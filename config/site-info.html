网站信息 ​

管理对用户公开展示的站点信息，不涉及密钥与支付，运营人员也可维护。

管理对用户公开展示的站点名称、Logo、备案与客服信息。与系统配置不同：此处不涉及密钥和支付，运营人员也可维护。

系统设置 → 网站信息全站
  • 文件存储已在系统配置中配好（上传 Logo 前）
  • 上线前名称与描述为必做项
基本信息站点名称、描述、SEO 与版本号
  1. 1
    进入网站信息系统设置 → 网站信息
  2. 2
    填写名称与描述上线前必做
  3. 3
    保存点击保存按钮
  4. 4
    客户端验证杀进程重进或下拉刷新，查看标题与关于页
网站名称 站点全称，如「灵萌校园」「XX 大学圈」展示：浏览器标题、分享卡片、部分页脚
网站简称 2～6 字短名称，如「灵萌」空间不足时的缩写展示
网站描述 1～2 句话站点简介，含核心功能SEO、分享摘要
关键词 逗号分隔 SEO 关键词，如 校园,社交,二手搜索引擎
版本号 如 v1.0.0，可与发版节奏同步客户端「关于」/ 设置页
Logo 与图标全站 Logo 与浏览器 Favicon

上传 Logo 前须已在系统配置 → 文件存储配好本地或云存储，否则选图失败。

网站 Logo PNG 透明底，建议 512×512 以内；从媒体库上传管理后台和部分 C 端位置
网站 Favicon 正方形 32×32 或 64×64保存后 H5 刷新才更新浏览器标签小图标
版权与备案
版权信息 如 © 2026 XX 科技有限公司页脚展示
ICP 备案号 如 京ICP备XXXXXXXX号国内站点强烈建议填写
公安备案号 如 京公网安备XXXXXXXXXXXX号可选
公安备案链接 与公安备案号成对出现beian.gov.cn 链接
客服信息
客服电话 通知模板等可使用变量展示
客服微信 用户联系客服
工作时间 如 工作日 9:00-18:00
只读信息页面底部系统字段
  • 配置 ID、创建时间、更新时间 — 用于与技术支持核对配置版本
与 UI 编辑器的关系网站信息 vs UI 管理分工
站点名称 网站信息为全站默认；UI 编辑器各页面导航标题可单独覆盖
Logo 网站信息为全站 Logo；TabBar、首页头图等在 UI 管理单独配
首页布局 不在网站信息配置；请用 UI 管理 → 页面配置 → 应用首页见 UI 可视化编辑器
验证 checklist
  • 网站名称、Logo 已保存
  • H5 打开站点，标签页标题正确
  • 页脚备案号可点击（若配置了公安链接）
  • 分享小程序卡片标题与描述合理（还可在 UI 页面配置里设分享标题/分享图）
