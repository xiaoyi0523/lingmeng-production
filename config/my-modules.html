本页目录

我的模块 ​

路径：系统设置 → 我的模块

查看当前站点已开通与未解锁的功能模块，以及授权状态、到期时间。侧栏菜单是否出现，首先看这里是否已开通。

什么时候来这页 ​

情况做什么
刚部署完核对商务承诺的模块是否都显示为「已开通」
侧栏没有外卖 / AI / 私信等先看是否在「未解锁」里
授权续期或加购模块后点 更新授权文件，再 刷新

页面怎么看 ​

顶部汇总大致包括：

信息含义
授权状态当前授权是否有效
已开通 / 未解锁模块数量
客户 / 到期 / 最大版本授权归属与有效期

下方分两块：

  • 已开通模块 — 侧栏对应功能一般可用（仍可能受账号权限限制）
  • 未解锁模块 — 需联系商务开通或更新授权

可用分类筛选：全部 / 基础内置 / 消息通讯 / 社区互动 / 交易营销 / 本地生活 / 基础设施 / 运营智能化。

操作步骤 ​

查看模块 ​

  1. 打开 系统设置 → 我的模块
  2. 用分类 pill 筛选你关心的模块
  3. 对照侧栏：已开通但仍看不到菜单 → 再查 账号权限

更新授权文件 ​

加购或续期后：

  1. 点 更新授权文件
  2. 确认提示：「将从授权站拉取当前站点的最新授权文件并部署到本地」
  3. 成功后点 刷新，确认新模块进入「已开通」

WARNING

请确认服务器能访问授权站，且站点授权编号/密钥正确。失败时页面会提示原因；也可联系交付方协助。

与「内测中」的区别 ​

显示含义
未解锁（我的模块）授权未包含该能力
侧栏「内测中」产品功能尚未对全部站点开放（如部分商户管理入口），即使授权也可能暂时无法进入
菜单灰色 / 无权限模块已开，但当前账号未分配 账号权限

常见问题 ​

现象处理
空态提示检查授权文件初始化向导或授权步骤未完成；联系交付方配置 license
更新授权后仍未解锁刷新页面；确认加购模块已写入授权站；核对站点标识是否正确
已开通但侧栏没有用超管登录对比；给当前账号分配对应菜单权限
