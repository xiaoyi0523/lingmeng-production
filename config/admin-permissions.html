账号权限与权限模板 ​

给运营、区域负责人分配菜单与按钮权限；未正确授权时侧栏空白或接口报无权限。

给运营、区域负责人分配「能看哪些菜单、能点哪些按钮」。未正确授权时，对方登录后台会侧栏空白或接口报无权限。

系统设置 → 账号权限 / 权限模板全站
  • 您是超级管理员，或已被授予账号权限 / 权限模板写权限
  • 目标账号已是管理员身份（平台管理员、区域主/子负责人等）
  • 系统设置类权限仅可授予超管或平台管理员，不能分给区域负责人

建议顺序

  1. 1
    权限模板按岗位建模板（如「内容运营」「区域客服」）
  2. 2
    账号权限选中账号 → 套用模板 → 个别增减 → 保存

重要变化

日常加人时：套用现成模板即可，不必每次从零勾选。

管理员账号必须配置授权（勾选权限或套用模板）后才能访问后台接口。未配置任何授权时，系统默认拒绝访问（超级管理员除外）。

权限模板

系统设置 → 权限模板

权限树顺序与侧栏一致：一级目录 → 二级目录 → 页面菜单 → 按钮。只勾菜单访问能进页面查列表；再勾按钮才能审核通过、删除、保存配置等写操作。

  1. 1
    新建模板点右上角 + 新建模板
  2. 2
    填写信息模板名称、描述（可选）、适用对象（平台管理员 / 区域负责人）
  3. 3
    勾选权限左侧选中模板，右侧勾选；可用全选 / 清空
  4. 4
    保存权限保存后会替换该模板全部授权项
编辑信息改名称、描述、适用对象
保存权限保存当前勾选；保存后会替换该模板全部授权项
删除删除模板；已套用该模板的账号需重新检查权限

账号权限

系统设置 → 账号权限
  • 解除模板：点解除仅取消与模板绑定；直接勾选的权限仍保留，需再保存确认
  • 超级管理员为全开权限，一般无需在本页逐项勾选
  1. 1
    找到账号用身份 Tab 或搜索，在左侧点选
  2. 2
    自定义身份名称可选，仅后台展示，如「XX 校区运营」
  3. 3
    套用模板推荐：选择模板后点套用
  4. 4
    增删权限按需调整菜单与按钮（可用全选 / 清空）
  5. 5
    保存保存后将替换该用户全部直接授权；已套用模板时与直接授权合并生效
顶部身份 Tab全部 / 超级管理员 / 平台管理员 / 区域子负责人 / 区域主负责人
搜索框昵称、账号、手机号、身份名称、UID
左侧列表可选账号；徽章「超管全开」「未授权」
右侧自定义身份名称、套用模板、权限树

验证是否生效

改权后仍像没生效？请对方退出重新登录。权限有短时缓存，多实例部署时一般会在保存后广播失效；仍不对可稍等片刻再试。

  1. 1
    重新登录用被授权账号退出再进管理后台
  2. 2
    侧栏检查应出现已勾选的菜单
  3. 3
    写操作检查打开审核通过等页面，确认按钮可用
  4. 4
    未授权项未授权菜单不应出现；强行访问接口应提示无权限

常见问题

提示「当前未配置任何授权…」必须勾选权限或套用模板后再保存，否则对方无法用后台
侧栏几乎是空的未保存授权，或只勾了按钮没勾菜单访问
能进页面但不能点通过/保存缺对应按钮权限
无法把系统配置分给区域负责人设计如此：系统设置类权限仅超管/平台管理员可持有
套用模板后权限不对先检查模板本身勾选项，再检查账号上是否又手工改过
