账号权限与权限模板 ​

路径：系统设置 → 账号权限 / 系统设置 → 权限模板

给运营、区域负责人分配「能看哪些菜单、能点哪些按钮」。未正确授权时，对方登录后台会侧栏空白或接口报无权限。

重要变化

管理员账号必须配置授权（勾选权限或套用模板）后才能访问后台接口。未配置任何授权时，系统默认拒绝访问（超级管理员除外）。

前置条件 ​

  • 您是超级管理员，或已被授予「账号权限 / 权限模板」写权限
  • 目标账号已是管理员身份（平台管理员、区域主/子负责人等），普通用户不会出现在可配置列表中
  • 系统设置类权限（系统配置、账号权限等）仅可授予超级管理员或平台管理员，不能分给区域负责人

推荐做法：先模板，再套用 ​

步骤菜单做什么
1权限模板按岗位建模板（如「内容运营」「区域客服」）
2账号权限选中账号 → 套用模板 → 个别增减 → 保存

日常加人时：套用现成模板即可，不必每次从零勾选。

一、权限模板 ​

路径：系统设置 → 权限模板

新建模板 ​

  1. 点右上角 + 新建模板
  2. 填写：
    • 模板名称（如「内容审核员」）
    • 描述（可选）
    • 适用对象：平台管理员 / 区域负责人
  3. 保存后，在左侧列表选中该模板
  4. 在右侧勾选权限（可用 全选 / 清空）
  5. 点 保存权限

权限树顺序与侧栏一致：一级目录 → 二级目录 → 页面菜单 → 按钮。

  • 只勾「菜单访问」：能进页面、能查列表
  • 再勾对应「按钮」：才能审核通过、删除、保存配置等写操作

维护模板 ​

操作说明
编辑信息改名称、描述、适用对象
保存权限保存当前勾选；保存后会替换该模板全部授权项
删除删除模板；已套用该模板的账号需重新检查权限

二、账号权限 ​

路径：系统设置 → 账号权限

界面说明 ​

区域作用
顶部身份 Tab全部 / 超级管理员 / 平台管理员 / 区域子负责人 / 区域主负责人
搜索框昵称、账号、手机号、身份名称、UID
左侧列表可选账号；徽章「超管全开」「未授权」
右侧自定义身份名称、套用模板、权限树
底部保存

给某人开通权限（完整步骤） ​

  1. 用身份 Tab 或搜索找到账号，在左侧点选
  2. （可选）填写 自定义身份名称（仅用于后台展示，如「XX 校区运营」）
  3. （推荐）在「套用模板」中选择模板 → 点 套用
  4. 按需增删菜单与按钮权限（可用全选 / 清空）
  5. 点 保存

保存后将替换该用户全部直接授权。已套用模板时，页面会提示「与直接授权合并生效」。

解除模板 ​

选中账号后点 解除，仅取消与模板的绑定；直接勾选的权限仍保留，需再保存确认。

超级管理员 ​

超级管理员为全开权限，一般无需在本页逐项勾选。列表可能显示「超管全开」。

三、验证是否生效 ​

  1. 用被授权账号重新登录管理后台（或退出再进）
  2. 侧栏应出现已勾选的菜单
  3. 打开一个写操作页面（如审核通过），确认按钮可用
  4. 未授权菜单不应出现；强行访问接口应提示无权限

改权后仍像没生效？

请对方退出重新登录。权限有短时缓存，多实例部署时一般会在保存后广播失效；仍不对可稍等片刻再试。

常见问题 ​

现象处理
左侧选中后提示「当前未配置任何授权…」必须勾选权限或套用模板后再保存，否则对方无法用后台
侧栏几乎是空的未保存授权，或只勾了按钮没勾菜单访问
能进页面但不能点「通过/保存」缺对应「按钮」权限
无法把「系统配置」分给区域负责人设计如此：系统设置类权限仅超管/平台管理员可持有
套用模板后权限不对先检查模板本身勾选项，再检查账号上是否又手工改过
