用户规则（区域用户配置） ​

路径：区域管理 → 用户配置

控制用户如何注册、登录、填写资料、签到、认证，可按区域分别设置。本文逐项说明每个开关/字段在 C 端（小程序 / H5）的实际表现，便于运营验收。

操作入口与配置继承 ​

后台怎么配 ​

  1. 打开 区域管理 → 用户配置
  2. 列表中点某条配置进入编辑弹窗（需有编辑权限）
  3. 新建时先选 目标区域：
    • 选 平台默认（区域编号 0）：全站兜底规则
    • 选具体区域：仅对该区域用户生效
  4. 改完点 保存

生效优先级（运营需理解） ​

用户所属区域实际读取哪份配置
某校区有专属配置用该校区配置
某校区无专属配置回退 平台默认（0）
平台默认也没有使用系统内置默认值（偏宽松：可注册、可登录等）

「启用」不是「回退平台默认」

某区域若已新建专属配置但把 启用 关掉，系统仍读取这条配置，且会直接拦截注册、登录、改资料，不会自动改用平台默认。

若希望某区域跟全站一致：不要为其单独建配置，或删除该区域专属行。

与区域列表的关系 ​

  • 区域列表（区域管理）：定义有哪些校区/社区、是否对用户可见、距离限制、私信开关等
  • 用户配置（本文）：定义用户在该区域的行为规则

两者独立配置，需配合使用。

一、注册与登录 ​

后台字段开启 / 关闭C 端表现验收要点
启用关该区域用户：无法注册、无法微信/密码登录、无法修改资料；提示「当前区域暂未开放…」用该区域测试账号分别试注册、登录、改昵称
启用开下方子开关按配置生效—
允许账号注册关注册页提交失败，提示「当前区域暂未开放注册」；微信首次授权若需自动注册也会受限于区域策略新用户走一遍注册
允许密码登录关用户名+密码登录失败，提示「当前区域暂未开放密码登录」；微信登录不受影响（若微信登录仍开启）密码登录与微信登录各测一次
允许微信小程序登录关小程序内微信授权登录失败，提示「当前区域暂未开放微信小程序登录」在小程序登录页测试
允许微信公众号登录关H5 / 公众号内微信登录失败，提示「当前区域暂未开放微信公众号登录」在 H5 登录页测试
注册强制验证码开注册时必须填写图形验证码，否则无法提交注册页应出现验证码
注册强制验证码关注册可不填验证码（仍受其他校验约束）—
登录强制验证码开密码登录时必须填验证码登录页出现验证码
登录强制验证码关密码登录无需验证码—

常见组合示例

运营目标建议配置
只要微信、不要账号密码关「允许密码登录」+ 开对应微信登录 + 关「允许账号注册」（若也不希望新用户用用户名注册）
校内只允许老用户登录关「允许账号注册」，保留登录方式
防机器注册开「注册强制验证码」

前置依赖：微信登录开关生效前，须先在 系统配置 → 微信小程序 / 微信公众号 填好 AppID 等，并完成 微信功能开启。

二、长度限制 ​

后台字段取值C 端表现
用户名最小 / 最大如 3～32注册时用户名过短/过长会提示，无法提交
密码最小 / 最大如 6～64注册或改密码时不符合长度会提示
昵称最小 / 最大如 1～50注册、改昵称、引导页填昵称时校验
简介最大长度如 500个人资料改简介时超出上限会提示

TIP

长度为 0 或未填 时按系统默认处理；改小最大值可能影响已有用户再次保存资料。

三、注册策略 ​

后台字段开启 / 取值C 端表现验收要点
注册时必须选择区域开账号密码注册时必须选所属区域，否则提示「请选择所属区域」多区域模式下注册页应出现区域选择
允许绑定推广人开注册时可携带推广人 ID，成功后尝试绑定推广关系（绑定失败不影响注册本身）带推广参数注册，后台查推广关系
允许绑定推广人关注册时忽略推广人绑定—
注册时使用更严格默认隐私开新用户默认：不可被搜索、点赞列表不可见、关注列表不可见新注册用户查隐私相关开关默认值
注册时使用更严格默认隐私关新用户使用系统默认隐私（相对开放）—
新用户信息模式跟随全站使用 系统配置 → 功能与上传 里的「新用户信息模式」—
新用户信息模式空白注册后昵称/头像为空或默认占位，用户需自行填写新用户资料页应较「空」
新用户信息模式随机头像昵称注册后自动分配随机昵称与头像新用户应有非空昵称头像
新用户信息模式头像库从头像库随机分配头像（昵称策略同随机模式）头像来自预设库

四、资料与审核（基础） ​

后台字段开启 / 关闭C 端表现
开启资料审核关用户改昵称/头像/简介/背景图（在允许修改的前提下）立即生效，无需等待审核
开启资料审核开命中「需审核字段」的修改进入待审；详见下文「资料审核详情」
允许修改昵称关个人资料页改昵称失败，「当前区域不允许修改昵称」
允许修改头像关无法更换头像
允许修改简介关无法改简介
允许修改背景图关无法改个人主页背景
昵称修改冷却（天）0不限次数
昵称修改冷却（天）N（如 7）N 天内再次改昵称会提示需等待，无法提交
资料完善阈值0～100用于资料完善度进度、引导页是否算「已完善」；默认 80。用户资料页可见完善度百分比
强制新用户引导开资料未完善时：发笔记、评论等关键操作会 Toast「请先完善个人资料」并跳转引导页；选区域后若资料不达标也会引导
强制新用户引导关不强制跳转引导页；部分场景改为弹出资料授权弹层（头像/昵称/性别）

强制引导与区域列表

区域 用户配置 里的「强制新用户引导」为主配置。若区域在 区域列表 里也开了同类开关，任一开启即视为开启（兼容旧数据）。

完善资料判定（C 端）：资料完善度 ≥ 阈值，或同时有有效头像 + 有效昵称（非「游客」「微信用户」等占位）。

五、用户标签 ​

后台字段开启 / 关闭C 端表现
开放用户标签关个人资料不展示标签能力；选标签、保存标签接口拒绝
开放用户标签开资料页可查看/选择标签（若允许编辑）
允许用户修改标签关标签只读，无法增删
允许用户修改标签开用户可自行调整标签
最少选择数0不强制选标签
最少选择数N保存资料时标签少于 N 个会提示
最多选择数N最多选 N 个，超出无法添加
标签计入资料完善度开选够标签会提高资料完善度百分比
标签计入资料完善度关标签不影响完善度计算

六、资料审核详情 ​

在 开启资料审核 的前提下生效。

后台字段取值C 端表现
需审核的资料字段不选默认审核：昵称、头像、简介、背景图
需审核的资料字段勾选部分仅勾选字段修改时才进审核
资料审核模式人工审核提交后待管理员/审核中心通过才对外展示新版本
资料审核模式自动通过提交后系统自动通过（仍走审核流程记录）
资料审核模式AI 审核由 AI 审核引擎判定（须已开启 AI 中台）
审核中对外展示 → 继续显示旧资料—他人和自己看到的仍是修改前的昵称/头像等，直到审核通过
审核中对外展示 → 隐藏待审字段—待审中的字段在资料页显示为空
审核中对外展示 → 显示占位内容—昵称/简介等显示「审核中」，头像/背景可能为空

用户本人资料页会标记 有待审资料；审核结果会通过站内通知等方式告知（以实际通知配置为准）。

七、认证与门禁 ​

后台字段开启 / 关闭C 端表现
开放学生认证关学生认证入口不可用；提交认证提示「当前区域暂未开放学生认证」
开放学生认证开用户可进入学生认证流程
要求学生认证通过关未认证用户正常使用发笔记、评论、私信、签到、发现流等（各业务自身规则仍适用）
要求学生认证通过开未通过学生认证（auth_status ≠ 已通过）的用户会被拦截，提示「请先完成学生认证后再使用该功能」。典型受限操作：发笔记、评论、发消息、签到、浏览发现流等
禁用手工提交学生认证开用户无法手动填写材料提交；仅适合纯官方渠道场景
禁用手工提交学生认证关可人工填写学校、学号、证件等提交审核

TIP

「开放学生认证」管有没有入口；「要求学生认证通过」管未认证能否用核心功能。两者需配合：要强制门禁时，两项通常都开。

管理员账号不受学生认证门禁限制。

八、账号安全与签到 ​

后台字段开启 / 关闭 / 取值C 端表现
允许账号注销关设置里无注销入口或提交失败
允许账号注销开用户可发起注销流程
允许绑定手机关无法绑定/换绑手机号
允许绑定手机开账号安全页可绑手机
允许绑定邮箱关无法绑定邮箱
允许绑定邮箱开可绑邮箱
开启签到关签到页不可用；签到接口拒绝
开启签到开每日签到、签到概览正常（仍受学生认证门禁约束，若开启）
注销确认冷却（小时）N发起注销后需等待 N 小时才真正执行（防误操作）
补签回溯天数N（默认 7）用户可对过去 N 天内漏签日期发起补签（若产品页有补签入口）

九、签到提醒（时间定义） ​

后台字段开启 / 取值C 端表现
开启签到订阅提醒关不向用户推送签到提醒类订阅消息
开启签到订阅提醒开按下方时刻，对「昨日已签、今日未签」且已授权订阅的用户推送小程序订阅消息
签到提醒推送时刻（时）0～23东八区每天该整点触发，如 10 = 10:00

INFO

用户须在前端授权过对应 订阅消息 模板，否则无法收到提醒。

十、登录安全 ​

后台字段取值C 端表现
登录失败锁定阈值0沿用全站登录失败锁定策略（见系统级安全配置）
登录失败锁定阈值N该区域用户密码登录连续失败 N 次后锁定
登录锁定时长（分钟）0沿用全站锁定时长
登录锁定时长（分钟）M锁定 M 分钟后自动解除

仅影响 密码登录 的失败计数；微信登录不走同一套密码失败锁定。

十一、文案与备注 ​

后台字段C 端表现
注册页说明展示在注册表单上方（富文本/纯文本以页面渲染为准）
登录页说明展示在登录表单上方
区域入口说明展示在区域选择/入口相关提示位
运营备注仅后台可见，C 端不展示

配置示例与验收清单 ​

示例 A：新校区 — 必须学生认证才能玩 ​

  1. 区域列表 新建「XX 大学」并 启用
  2. 用户配置 为该区域新建配置，启用 打开
  3. 开「开放学生认证」+ 开「要求学生认证通过」
  4. 按需开「强制新用户引导」

验收

  • [ ] 未认证用户发笔记 / 评论 / 私信 / 签到应被拦截并提示认证
  • [ ] 认证通过后上述功能恢复
  • [ ] 资料未完善时引导页逻辑符合预期

示例 B：全站仅微信登录 ​

  1. 编辑 平台默认（0）
  2. 关「允许密码登录」、关「允许账号注册」（可选）
  3. 开「允许微信小程序登录」

验收

  • [ ] 小程序可微信登录
  • [ ] 密码登录明确失败提示
  • [ ] 系统配置里微信 AppID 已生效

示例 C：资料改完需人工审 ​

  1. 开「开启资料审核」
  2. 审核模式选 人工审核
  3. 「审核中对外展示」选 继续显示旧资料

验收

  • [ ] 用户改昵称后对外仍显示旧昵称
  • [ ] 本人能看到待审状态
  • [ ] 后台审核通过后新昵称生效
