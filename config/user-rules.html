用户规则（区域用户配置） ​

控制用户如何注册、登录、填写资料、签到、认证，可按区域分别设置。

控制用户如何注册、登录、填写资料、签到、认证，可按区域分别设置。逐项说明每个开关/字段在 C 端（小程序 / H5）的实际表现，便于运营验收。

区域管理 → 用户配置区域

操作入口与配置继承

区域列表定义有哪些校区/社区、是否可见、距离限制、私信开关等；用户配置定义用户在该区域的行为规则。两者独立配置，需配合使用。

某区域若已新建专属配置但把启用关掉，系统仍读取这条配置且会直接拦截注册、登录、改资料，不会自动改用平台默认。若希望跟全站一致：不要为其单独建配置，或删除该区域专属行。

  1. 1
    打开用户配置区域管理 → 用户配置
  2. 2
    进入编辑列表中点某条配置（需编辑权限）
  3. 3
    选择目标区域平台默认（0）为全站兜底；选具体区域仅对该区域生效
  4. 4
    保存改完点保存
某校区有专属配置用该校区配置
某校区无专属配置回退平台默认（0）
平台默认也没有使用系统内置默认值（偏宽松：可注册、可登录等）

注册与登录

微信登录开关生效前，须先在系统配置填好 AppID 等，并完成微信功能开启。

  • 只要微信、不要账号密码：关密码登录 + 开对应微信登录 + 可选关账号注册
  • 校内只允许老用户登录：关账号注册，保留登录方式
  • 防机器注册：开注册强制验证码
启用（关）无法注册、无法微信/密码登录、无法修改资料；提示「当前区域暂未开放…」
允许账号注册（关）注册页提交失败；微信首次授权若需自动注册也受限
允许密码登录（关）用户名+密码登录失败；微信登录不受影响（若仍开启）
允许微信小程序登录（关）小程序内微信授权登录失败
允许微信公众号登录（关）H5 / 公众号内微信登录失败
注册/登录强制验证码（开）注册或密码登录时必须填写图形验证码

长度限制

长度为 0 或未填时按系统默认处理；改小最大值可能影响已有用户再次保存资料。

用户名最小 / 最大如 3～32；注册时过短/过长会提示
密码最小 / 最大如 6～64；注册或改密码时校验
昵称最小 / 最大如 1～50；注册、改昵称、引导页填昵称时校验
简介最大长度如 500；个人资料改简介时超出上限会提示

注册策略

注册时必须选择区域开：账号密码注册时必须选所属区域
允许绑定推广人开：注册时可携带推广人 ID；关：忽略推广人绑定
注册时使用更严格默认隐私开：新用户默认不可被搜索、点赞/关注列表不可见
新用户信息模式跟随全站 / 空白 / 随机头像昵称 / 头像库跟随全站见系统配置 → 功能与上传

资料与审核（基础）

区域用户配置里的强制新用户引导为主配置；区域列表里同类开关任一开启即视为开启。完善资料判定：完善度 ≥ 阈值，或同时有有效头像 + 有效昵称。

开启资料审核（关）改昵称/头像/简介/背景图立即生效，无需等待审核
允许修改昵称/头像/简介/背景图关：对应修改失败并提示当前区域不允许
昵称修改冷却（天）N 天内再次改昵称会提示需等待
资料完善阈值0～100，用于完善度进度与引导页判定，默认 80
强制新用户引导开：资料未完善时发笔记/评论等会 Toast 并跳转引导页

用户标签

开放用户标签关：资料页不展示标签能力；开：可查看/选择标签
允许用户修改标签关：标签只读
最少 / 最多选择数保存资料时校验标签数量
标签计入资料完善度开：选够标签会提高完善度百分比

资料审核详情

在开启资料审核的前提下生效
  • 用户本人资料页会标记有待审资料；审核结果通过站内通知等方式告知
需审核的资料字段不选则默认审核昵称、头像、简介、背景图
资料审核模式人工审核 / 自动通过 / AI 审核（须已开启 AI 中台）
审核中对外展示继续显示旧资料 / 隐藏待审字段 / 显示占位内容（审核中）

认证与门禁

开放学生认证管有没有入口；要求学生认证通过管未认证能否用核心功能。要强制门禁时两项通常都开。管理员账号不受学生认证门禁限制。

开放学生认证（关）学生认证入口不可用
要求学生认证通过（开）未通过认证用户被拦截发笔记、评论、私信、签到、发现流等
禁用手工提交学生认证开：用户无法手动填写材料提交

账号安全与签到

允许账号注销关：设置里无注销入口或提交失败
允许绑定手机 / 邮箱关：无法绑定或换绑
开启签到关：签到页不可用；开：每日签到正常（仍受学生认证门禁约束）
注销确认冷却（小时）发起注销后需等待 N 小时才真正执行
补签回溯天数默认 7；可对过去 N 天内漏签日期补签

签到提醒

用户须在前端授权过对应订阅消息模板，否则无法收到提醒。

开启签到订阅提醒关：不推送；开：对「昨日已签、今日未签」且已授权订阅的用户推送
签到提醒推送时刻（时）0～23，东八区每天该整点触发，如 10 = 10:00

登录安全

仅影响密码登录的失败计数；微信登录不走同一套密码失败锁定。

登录失败锁定阈值0 沿用全站策略；N 则该区域密码登录连续失败 N 次后锁定
登录锁定时长（分钟）0 沿用全站；M 则锁定 M 分钟后自动解除

配置示例与验收

三个常见运营场景
  • 示例 A — 新校区必须学生认证：区域列表新建并启用 → 用户配置开启用 + 开学生认证 + 开认证门禁 → 未认证用户发笔记/评论/私信/签到应被拦截
  • 示例 B — 全站仅微信登录：编辑平台默认 → 关密码登录、关账号注册（可选）→ 开微信小程序登录 → 小程序可微信登录、密码登录明确失败
  • 示例 C — 资料改完需人工审：开资料审核 + 人工审核 + 审核中继续显示旧资料 → 改昵称后对外仍显示旧昵称，后台通过后生效
