区域管理 ​

灵萌支持多区域（多校区、多社区）独立运营。本文说明 区域列表 各字段与 系统级区域模式 对用户端（C 端）的影响；用户注册登录、资料、签到等规则见 用户规则。

一、区域列表 ​

路径：区域管理 → 区域列表

常用操作 ​

操作说明
新建区域填写名称、类型、地址、坐标等
编辑修改区域信息与开关
启用 / 禁用控制区域是否对 C 端可见、可选
负责人设置主负责人与子负责人

基础信息字段 → C 端影响 ​

后台字段C 端表现验收要点
区域名称区域选择页、切换区域、部分内容卡片上显示的名称改名后 C 端列表同步更新
区域类型校园 / 社区 / 其他；用于区域页筛选 Tab筛选「校园」仅显示 campus 类型
地址区域详情/列表辅助展示—
Logo区域选择卡片左侧图标；无 Logo 时显示名称首字上传后 C 端可见
背景图区域相关展示位（若有）—
相册区域介绍类页面轮播（若前端有接入）—
负责人后台管理用；C 端一般不直接展示负责人表单字段—

位置信息 → C 端影响 ​

后台字段取值C 端表现
纬度 / 经度有效坐标区域选择页可计算「距你 XXX m/km」；配合距离限制过滤
纬度 / 经度0 或未填距离标签显示「距你 --」；不参与按距离过滤
距离限制（米）0不限距离，列表显示所有已启用区域（仍受系统级距离策略约束，见下文）
距离限制（米）N（如 1000）单区域维度的距离参考；与系统 区域配置 Tab 的全局距离限制叠加使用时，以 C 端区域页逻辑为准：用户定位可用时，超出限制的区域可能不出现在可选列表

TIP

运营上建议：每个对外开放的校区都填好坐标，否则用户看不到距离，也无法按距离筛选。

开关选项 → C 端影响 ​

后台字段开启关闭C 端表现
热门是否区域选择页「热门」筛选下展示；列表排序热门优先
区域私信开启关闭开启：用户可正常使用私信、群聊（仍受笔记/消息等业务规则约束）
关闭：普通用户私信/群聊入口隐藏或不可用；仅保留与官方机器人账号的私聊
允许提现开启关闭与全站提现总开关 同时 为开时，该区域用户才可发起提现
提现手续费 / 费率数值—该区域用户提现时按配置计费（C 端提现页展示金额会体现规则）

区域私信 vs 全站

未绑定区域的用户，是否可私信由 系统配置 中的「无区域用户私信」类开关决定（见 系统配置）。
已绑定区域的用户，以 区域列表 → 区域私信 为准。

启用 / 禁用（status） ​

状态C 端表现
启用区域出现在 C 端区域列表（status=1 查询）；用户可选、可绑定
禁用C 端区域列表不展示该区域；已绑定该区的老用户行为取决于业务（内容仍可能带历史 region_id，但新区不可选）

验收：禁用某区域后，打开 C 端区域选择页，该区域应消失。

平台默认（region_id = 0） ​

  • 在 用户配置 等页面中，平台默认 表示全站兜底规则，不是一条真实「校区」记录
  • 未单独配置的子区域，其 用户规则 继承平台默认；详见 用户规则 → 配置继承

二、系统级区域模式 ​

路径：系统设置 → 系统配置 → 区域配置 Tab

与区域列表配合：此处定「用户怎么进区域」，区域列表定 「有哪些区域」。

字段说明
区域模式见下表
固定区域模式为「固定区域」时，选择具体区域，不能选 0
距离限制（米）全站默认距离过滤半径，默认 1000；用户授权定位后，区域选择页可能隐藏超出该距离的区域

三种模式 → C 端表现 ​

模式后台配置C 端表现
平台模式（全站单区）single_region_id = 0用户无需选区域；新用户不强制绑定具体校区；跳过区域选择页
多区域自选不设置固定 ID（null）注册或首次进入时需进入 区域选择页 挑选校区/社区；选完后写入本地与账号
固定区域指定某一区域 ID新用户自动绑定该区域；跳过区域选择页

已绑定用户

用户账号 已有 region_id 时，一般不允许再到区域页随意切换（防止跨区运营混乱）。换区通常需后台改用户所属区域或走专门业务流程。

距离限制如何作用在 C 端 ​

  1. 用户打开 区域选择页 并授权定位
  2. 读取系统 区域配置 Tab 的「距离限制（米）」
  3. 对每个 已启用 且 有坐标 的区域计算球面距离
  4. 超出限制的区域 不出现在可选列表（热门筛选同样受约束）

验收 checklist

  • [ ] 三种区域模式各测一遍：是否出现区域页、新用户 region 是否正确
  • [ ] 距离限制设为 500m：远端校区在列表中消失
  • [ ] 关闭定位权限：列表应仍展示区域，但距离显示「距你 --」

三、各业务「区域 ×× 配置」 ​

在 区域管理 菜单下，除 用户配置 外还有按业务的区域配置页。每个页面顶部的 「启用」 一般表示：关闭后，该区域 C 端用户看不到或不生效对应功能模块（具体以各模块文档为准）。

菜单作用C 端关联
用户配置注册登录、资料、认证、签到登录注册、资料页、引导页、签到页
笔记配置发笔记、评论、审核、浏览量发笔记、圈子笔记流
话题配置话题模块话题广场、话题详情
投票配置投票活动投票参与页
评选活动配置评选模块评选活动页
闲置配置二手闲置闲置发布与交易
评分配置区域评分评分相关页
等级特权用户等级权益等级特权展示与领取
笔记热度 / 热帖精帖内容排序首页/圈子排序结果

推荐配置顺序

  1. 系统配置 → 区域配置 选定模式与全站距离
  2. 区域列表 创建并 启用 具体区域，填坐标与 Logo
  3. 用户配置 打开 启用，设置注册登录与门禁
  4. 按需打开笔记、话题等业务区域配置

四、区域管理与用户规则对照 ​

运营常把两类配置混在一起，可按下表区分：

需求改哪里
关闭某校区注册 / 微信登录用户配置
强制学生认证才能发笔记用户配置
某校区不在列表展示区域列表 → 禁用
某校区用户不能互相私信区域列表 → 区域私信 → 关闭
用户必须先选校区系统配置 → 多区域自选 + 用户配置「注册时必须选择区域」
全站只有一个虚拟区域系统配置 → 平台模式
新用户全部进「XX 大学」系统配置 → 固定区域 选该校
