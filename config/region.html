区域管理 ​

灵萌支持多区域（多校区、多社区）独立运营。系统配置 → 区域配置 提供「平台模式 / 多区域自选 / 固定区域」三选一；区域列表 维护具体校区。注册登录等规则见 用户规则。

灵萌支持多区域（多校区、多社区）独立运营。系统配置 → 区域配置 Tab 提供「平台模式 / 多区域自选 / 固定区域」三选一，决定用户要不要选校区、能不能进平台页；区域列表则维护具体校区信息与开关。注册登录等规则见用户规则。

区域管理 → 区域列表 / 系统设置 → 系统配置 → 区域配置区域

建议顺序

  1. 1
    系统配置 → 区域配置 Tab三选一：平台 / 多区域自选 / 固定区域
  2. 2
    区域列表创建并启用具体区域，填坐标与 Logo
  3. 3
    用户配置打开启用，设置注册登录与门禁
  4. 4
    业务区域配置按需打开笔记、话题等模块

区域列表操作

区域管理 → 区域列表
新建区域填写名称、类型、地址、坐标等
编辑修改区域信息与开关
启用 / 禁用控制区域是否对 C 端可见、可选
负责人设置主负责人与子负责人

基础信息 → C 端影响

区域名称区域选择页、切换区域、内容卡片上显示的名称改名后 C 端列表同步更新
区域类型校园 / 社区 / 其他；用于区域页筛选 Tab筛选「校园」仅显示 campus 类型
地址区域详情/列表辅助展示
Logo区域选择卡片左侧图标；无 Logo 时显示名称首字
背景图 / 相册区域相关展示位与介绍页轮播（若前端有接入）
负责人后台管理用；C 端一般不直接展示

位置信息 → C 端影响

运营上建议：每个对外开放的校区都填好坐标，否则用户看不到距离，也无法按距离筛选。

纬度 / 经度（有效）区域选择页可计算「距你 XXX m/km」；配合距离限制过滤
纬度 / 经度（0 或未填）距离标签显示「距你 --」；不参与按距离过滤
距离限制（米）= 0不限距离，列表显示所有已启用区域（仍受系统级距离策略约束）
距离限制（米）= N单区域维度距离参考；与系统区域配置 Tab 全局距离限制叠加

开关选项 → C 端影响

未绑定区域的用户，是否可私信由系统配置中的「无区域用户私信」类开关决定。已绑定区域的用户，以区域列表 → 区域私信为准。

热门开启：区域选择页「热门」筛选下展示，列表排序热门优先
区域私信开启：用户可正常私信/群聊；关闭：普通用户私信/群聊不可用，仅保留与官方机器人私聊
允许提现与全站提现总开关同时为开时，该区域用户才可发起提现
提现手续费 / 费率该区域用户提现时按配置计费

启用 / 禁用（status）

启用区域出现在 C 端区域列表；用户可选、可绑定
禁用C 端区域列表不展示；已绑定老用户行为取决于业务
  • 禁用某区域后，打开 C 端区域选择页，该区域应消失

平台默认（region_id = 0）

  • 在「用户配置 / 笔记配置」等页面中，region_id = 0 表示全站兜底规则，不是一条真实校区记录
  • 未单独配置的子区域，其业务规则继承平台默认行
  • 与「平台模式」不同：平台模式是系统级策略（用户不绑定区域）；平台默认行是各业务配置的模板

系统级区域模式（后台入口）

系统设置 → 系统配置 → 区域配置 Tab

与区域列表配合：此处定「用户怎么进区域」，区域列表定「有哪些区域」。保存后立即影响 C 端门控。

  1. 1
    打开区域配置 Tab见三个模式胶囊：平台模式 / 多区域自选 / 固定区域
  2. 2
    选择一种模式点击对应胶囊；选「固定区域」时须填写或点「选择」指定校区
  3. 3
    多区域自选时（可选）按需开关「首次须选区域」「隐藏平台入口」
  4. 4
    设置距离限制全站默认半径（米），默认 1000
  5. 5
    保存建议用新账号或清缓存后验收 C 端表现
区域模式三选一：平台模式 / 多区域自选 / 固定区域
固定区域仅固定区域模式：填写区域编号或点「选择」从列表挑选，不能填 0
首次须选区域仅多区域自选：开启 = 新用户须先进入区域选择页；关闭 = 可直接以平台页进入
隐藏平台入口仅多区域自选：开启 = 区域选择页不展示「平台」选项，用户只能选具体校区
距离限制（米）全站默认距离过滤半径，默认 1000；用户授权定位后可能隐藏超出距离的区域

三种模式 → C 端表现

距离限制对三种模式均生效：超出半径的校区不会出现在可选列表（需用户授权定位）。

  • 多区域自选 + 首次须选区域（开）：未选区时先进区域选择页，选完才进入首页
  • 多区域自选 + 首次须选区域（关）：可直接进入平台页（region_id = 0），之后仍可手动换区
  • 多区域自选 + 隐藏平台入口（开）：选择页只列具体校区，不允许选「平台」
  • 账号已绑定 region_id 后：一般不能再随意切换，需后台改用户所属区域或走专门业务流程
平台模式全站不绑定区域。新用户注册时不写入 region_id；跳过区域选择页；生效区域始终为 0（平台页）适合单社区、无多校区概念，或内容不按校区隔离
多区域自选用户可在区域选择页切换校区，或选择「平台」入口（若未隐藏）。已绑定区域的老用户不能随意换区适合多校区；配合「首次须选区域」「隐藏平台入口」微调体验
固定区域指定某一校区 ID。新用户自动绑定该区域；跳过区域选择页；全站按该校区规则运营适合只为一个学校/社区部署，不希望用户看到选区页

距离限制如何作用

  1. 1
    打开区域选择页用户授权定位
  2. 2
    读取系统距离限制区域配置 Tab 的「距离限制（米）」
  3. 3
    计算球面距离对每个已启用且有坐标的区域
  4. 4
    过滤列表超出限制的区域不出现在可选列表（热门筛选同样受约束）
  • 三种区域模式各测一遍：是否出现区域页、新用户 region 是否正确
  • 多区域自选：分别测试「首次须选区域」开/关、「隐藏平台入口」开/关
  • 固定区域：新注册用户应自动绑定指定校区，且不出现选区页
  • 距离限制设为 500m：远端校区在列表中消失
  • 关闭定位权限：列表仍展示区域，但距离显示「距你 --」

常见运营场景怎么选

只有一个社区，不分校区平台模式用户无感知选区
多校区，用户必须选校多区域自选 + 首次须选区域（开）+ 隐藏平台入口（开）纯多校运营
多校区，但允许逛「全站/platform」多区域自选 + 首次须选区域（关或开）+ 隐藏平台入口（关）平台页作兜底
只服务某一所大学固定区域 → 选择该校新用户自动进校

老用户换校区后台改用户所属区域已绑定用户前端一般不能自换

常见问题

后台只有三个胶囊，找不到 single_region_id 字段？已改为可视化三选一：平台模式存 0，多区域自选存空，固定区域存具体编号。无需手填 JSON。
从旧版升级后默认是什么模式？历史未配置的记录会归一为平台模式（不绑定区域）。若您原本是多校区运营，请主动改为「多区域自选」并创建区域列表。
「平台模式」和配置页里的「平台默认（region_id=0）」是一回事吗？不是。平台模式是用户策略；平台默认行是笔记/用户等业务的兜底配置模板。平台模式下用户 region_id 为 0，业务规则读平台默认行。
固定区域模式下还能在区域列表加新校区吗？可以维护列表，但新用户只会自动绑定您指定的固定区域；其他校区不会出现在用户选区流程中。
