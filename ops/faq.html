常见问题 ​

汇总站点管理员在后台配置与日常运营中最常遇到的问题及处理思路，按现象分类对照跳转至对应功能文档。

汇总站点管理员在后台配置与日常运营中最常遇到的问题及处理思路，按现象分类对照排查。

运维 · 常见问题·站点管理员故障排查
  • 已能登录管理后台（H5）
  • 已知管理员类型：超级管理员、平台管理员或区域管理员

侧栏菜单没有或显示「未解锁 / 内测中」

详见进入管理后台与各功能文档前置条件。

可能原因有哪些？功能模块未授权（外卖、AI 中台、UI 管理等需授权）；账号权限不足导致侧栏整组隐藏；商户管理内测时外卖 / 骑手整组可能不可点。
如何处理？超级管理员在 系统设置 → 账号权限 添加所需权限或使用权限模板；到 系统设置 → 我的模块 确认模块已开通；区域管理员只能看到被授权且在本区域范围内的菜单。

操作保存时提示 403 / 无权限

可能原因有哪些？当前账号缺少对应功能的修改权限；区域管理员修改其他区域数据被拒绝；站点已关闭「遗留全量权限」，未单独分配权限的管理员默认无法保存。
如何处理？让超级管理员在 系统设置 → 账号权限 中补充权限；区域管理员切换页面顶部区域筛选到管辖区域再保存；使用权限模板批量绑定常用角色。

微信登录失败

可能原因有哪些？系统配置 → 微信小程序 / 公众号 Token 测试未通过；区域管理 → 用户配置 未开启微信登录；公众号网页授权域名与站点域名不一致；小程序体验版用户未加入体验成员。
如何处理？按微信文档从 Token 测试到区域开关逐项核对。

支付成功但订单 / 余额未更新

可能原因有哪些？微信 / 支付宝回调 URL 未配置或域名错误；商户 API 证书与平台公钥不匹配；反向代理缓存了 POST 请求。
如何处理？核对回调：微信 https://你的域名/api/payment/wx-notify，支付宝 https://你的域名/api/payment/alipay-notify；查看 系统监控 → 系统状态 与 财务管理 → 资金交易；详见支付与提现文档。

WebSocket 连不上 / 消息一直连接中

可能原因有哪些？Go 未运行；Nginx 未转发 Upgrade 头；CDN 未开 WebSocket；config.yaml 的 cors.allowed_origins 只有 http:// 而站点用 https:// 访问（GET /ws 返回 403）。
如何处理？见运维文档 WebSocket 连接排查：白名单补 https Origin、重启进程；curl 自检 /ws 应返回 401 而非 403。

用户收不到短信 / 推送 / 微信通知

可能原因有哪些？系统配置 → 腾讯云短信 未填或模板错误；通知控制台 → 事件模板 未勾选对应渠道；App Push 需运维配置 FCM / APNs 环境变量；用户处于静默时段或未订阅小程序消息。
如何处理？短信、通知与推送分渠道排查；在 通知控制台 → 消息链路追踪 查看失败原因。

搜索不到新内容

可能原因有哪些？Meilisearch 未启动或密钥不一致；索引尚未同步。
如何处理？在 系统监控 → 搜索索引 查看状态；必要时联系运维启动可选基础设施并重建索引；见搜索与推荐文档。

外卖 / 跑腿无入口或无人接单

可能原因有哪些？区域外卖配置 / 跑腿区域配置 未启用；UI TabBar 未添加 Tab；骑手审核通过人数不足或骑手未上线。
如何处理？外卖、跑腿、骑手文档串联排查区域配置、TabBar 与骑手审核状态。

无法进入管理后台

可能原因有哪些？非 H5 环境（管理端仅浏览器 H5）；账号类型不是超级管理员 / 平台管理员 / 区域管理员；未登录或登录过期。
如何处理？使用 Chrome 等浏览器打开 https://你的域名/pages_admin/index/index（不是文档站地址）；确认账号类型，普通用户无后台入口。

区域配置

某区域功能与其他区域不一致？检查是否只改了「平台默认」未改该区域行。
区域管理员看不到数据？在 系统设置 → 账号权限 中确认该账号的管辖区域是否包含目标区域。
如何关闭某区域私信？在 区域列表 编辑对应区域。

其他补充

改了配置客户端仍旧样？客户端缓存：杀进程重进；UI 配置需匹配同一区域。部分系统配置保存后立即生效，微信 Token 类需点「获取 Token」验证。
找谁处理？菜单、区域规则、活动配置 → 站点管理员；服务器、Docker、环境变量、备份 → 运维；授权模块开通 → 授权 / 商务。

验证是否生效

解决任一问题后，用最小复现路径再测一次
  • 单用户微信登录、单笔支付、单条搜索等最小路径复测
  • 在对应监控 / 流水菜单确认记录正常
