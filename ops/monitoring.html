系统监控入口 ​

功能说明 ​

说明管理后台 系统监控 分组各菜单的用途，便于管理员日常巡检与问题定位。

前置条件 ​

  • 已登录管理后台 H5。
  • 账号具备 system.monitor:read 或相应模块读权限（部分菜单需更高权限）。

管理后台配置步骤 ​

路径：侧栏 系统监控（无需额外「开启」，部署正常即可用）

菜单管理员何时使用
数据统计查看用户、内容、订单等运营概览
系统状态每日巡检：数据库、Redis、支付回调、队列是否正常
服务健康中心查看各依赖服务自愈状态与历史告警
运行时指标内存、 Goroutine 等资源占用偏高时
API 指标接口延迟、错误率突增时
数据库性能慢查询、连接池紧张时
定时任务确认同步、对账、Token 刷新等任务在跑
搜索索引Meilisearch 同步与重建，见 搜索与推荐
相关推荐评估启用 Gorse 后查看推荐效果
对账中心支付 / 资金异常对账
链接巡检笔记外链失效批量检测
联动中心跨模块联动任务状态
导出任务异步导出 Excel 等任务进度
系统动态健康巡检写入的告警时间线
在线用户当前 WebSocket 在线规模

建议巡检节奏 ​

频率查看菜单
每日系统状态、定时任务
每周数据统计、搜索索引
出问题时系统动态 → API 指标 / 消息链路追踪（通知模块）

区域配置 ​

监控数据 全站汇总；区域管理员若被授权，部分列表（如用户、内容）会按区域过滤，但 系统状态 仍为全站视角。

验证是否生效 ​

  1. 打开 系统监控 → 系统状态，各核心依赖显示绿色或「正常」。
  2. 定时任务 列表最近执行时间在预期范围内（如微信 Token 刷新、搜索同步）。
  3. 故意断开 Redis（仅测试环境）后，系统动态 出现告警记录（生产勿试）。

常见问题 ​

菜单缺失

  • 账号权限不足；见 常见问题「403 / 菜单没有」。
  • 部分菜单依赖可选模块（如 搜索索引 需搜索能力）。

看不懂指标

  • 管理员优先看 系统状态 红字与 系统动态 文案；细粒度 Prometheus 由运维接入 Grafana。

与通知控制台的区别

  • 系统监控：基础设施与任务。
  • 通知控制台：业务通知模板与用户消息投递。
