闲置交易 ​

按区域开启闲置物品发布与交易，并配置展示规则、联系方式与交易约束。

校区二手集市：按校区开关，支持出售/求购，可选平台担保交易（在线付款）。闲置信息通常挂在笔记里一起展示。

区域管理 → 闲置配置闲置交易
  • 目标校区已在区域列表中创建
  • 文件存储可用（商品图走笔记图片）
  • 开启担保交易时需完成支付配置
  • 闲置模块已在我的模块中开通

建议顺序

  1. 1
    开闲置配置区域管理 → 闲置配置：选校区，打开「启用闲置」
  2. 2
    定交易规则选择出售/求购、是否担保交易、价格区间与发布限制
  3. 3
    配发布入口TabBar发布弹窗勾选「发闲置」；圈子页可筛闲置笔记
  4. 4
    客户端验收发一条出售闲置，走联系或下单支付全流程

区域与平台默认

页面标题为「区域闲置配置」，侧栏菜单名「闲置配置」。平台默认（region_id = 0）是模板；校区没单独保存时自动沿用。

总开关与发布类型

启用闲置必填关掉后该校区不能发、不能看闲置列表
允许出售用户可标价格卖东西
允许求购用户可发求购帖
允许面议售价为 0 表示面议（需单独开启）

交易闭环

没配支付就开担保交易，用户下单会失败。

  • 关闭担保交易时，用户只能「联系卖家」线下成交，再手动标记完成
  • 开担保交易前务必先配好微信支付等（见支付与提现文档）
开启担保交易买家在线付款，平台托管，确认收货后成交；走统一订单与支付
出售需卖家确认买家点购买后，卖家确认才生成支付单

字数、条数与价格

标题/描述字数、最多图片数发布时后端校验，0 多表示不限制（图片默认上限 9）
每用户每日发布上限防刷屏，0 表示不限
出售最低价/最高价、求购预算区间单位元，0 表示不限制

列表与审核

闲置挂在笔记上发布。笔记配置若「先审后发」，闲置也会等笔记过审后才公开（可配合「笔记未通过前隐藏」）。

默认排序圈子闲置列表按最新发布或价格等排序
列表展示已成交 / 求购控制圈子里是否显示已卖出、求购帖
笔记未通过前隐藏关联笔记还在审核时，不出现在闲置列表

内容管理与客诉

社交圈子 → 笔记管理闲置以笔记形式展示，违规信息在此下架
用户体系 → 平台举报处理虚假交易、违禁品等举报
财务管理 → 资金交易担保交易订单可对支付流水

客户端入口

  • UI管理 → TabBar配置 → 发布弹窗：勾选「发闲置」
  • 圈子/首页列表：笔记列表组件可筛 idle_only（仅闲置）
  • 搜索：全站搜索 type=idle 可搜闲置标题

验证是否生效

  • 闲置配置中测试校区已启用
  • 客户端发布弹窗有「发闲置」，能成功发帖
  • 若开担保交易：测试下单支付成功，卖家确认收货后状态变已成交
  • 若仅线下：联系卖家、标记完成流程正常

常见问题

没有发闲置入口闲置配置该校区是否启用；我的模块是否含 idle；TabBar 发布弹窗是否勾选发闲置。
提示价格不合法检查配置的出售最低价/最高价或求购预算区间；面议是否允许售价为 0。
发了但列表里没有笔记是否还在审核；是否开启「笔记未通过前隐藏」；列表是否隐藏了求购/已成交。
买家付不了款是否开启担保交易；支付是否配置完成；卖家是否需确认但未点确认。
一天发多条被拦「每用户每日发布上限」；可对该校区调高或设 0 不限。
图片上传失败查文件存储配置；笔记配置的图片数量/大小限制。
改了平台默认某校区没变该校区已有单独闲置配置行，不会继承平台默认，需进该校区编辑。
