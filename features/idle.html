闲置交易 ​

功能说明 ​

按区域开启闲置物品发布与交易，并配置展示规则、联系方式与交易约束。

前置条件 ​

  • 目标区域已创建。
  • 文件存储可用（闲置商品图）。
  • 若涉及在线付款，需配置 支付与提现。

管理后台配置步骤 ​

路径：区域管理 → 闲置配置

在列表中选择 平台默认 或具体区域，编辑：

  • 是否启用闲置模块
  • 发布字段要求（价格、成色、交易方式等，以页面为准）
  • 是否需审核后展示
  • 联系方式展示规则（私信 / 电话等）

保存后对应该区域立即生效（客户端需刷新或重新进入页面）。

内容管理 ​

用户发布的闲置信息可在以下位置监管：

菜单作用
社交圈子 → 笔记管理部分闲置以笔记形式展示时可统一下架
用户体系 → 平台举报处理违规闲置信息

区域配置 ​

闲置为 纯区域级 功能：区域管理 → 闲置配置 中每一行对应一个 region_id。

  • 平台默认：新区域未单独配置时的兜底
  • 某区域关闭闲置：仅编辑该区域行并关闭启用开关

验证是否生效 ​

  1. 在 闲置配置 中开启测试区域。
  2. 客户端切换至该区域，出现闲置发布入口，成功发布一条带图闲置。
  3. 关闭该区域闲置后，入口隐藏或提示功能未开放。

常见问题 ​

没有闲置入口

  • 闲置配置 中该区域未启用。
  • UI管理 → TabBar配置 / 页面配置 未展示闲置 Tab。

无法上传图片

  • 检查 文件存储 与 笔记配置 中的图片相关限制。

交易纠纷

  • 平台通常仅提供信息展示；在线支付订单可在 财务管理 → 资金交易 查流水，结合 平台举报 处理。
