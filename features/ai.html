AI 中台 ​

统一管理大模型供应商、模型、场景路由与配额，为官方机器人 AI 回复、智能评论等能力提供底层 AI 服务。

统一管理大模型供应商、模型、场景路由与配额，为官方机器人 AI 回复、智能评论等能力提供底层 AI 服务。

AI中台AI 中台
  • AI 中台模块已在授权中开通
  • 已在各模型供应商处开通 API 并获取密钥
  • 账号具备 AI 中台相关读写权限

建议顺序

  1. 1
    供应商管理新增供应商，填写 API Key、Base URL，连通/拨测通过
  2. 2
    模型管理注册模型 ID，设置上下文长度、温度等
  3. 3
    场景路由为各业务场景指定主模型与可选降级模型
  4. 4
    在线验证AI 对话页测试回复；业务侧开启 AI 后查用量与日志

供应商配置（具体操作）

路径：AI中台 → 供应商管理。建议先配通一家供应商，再注册模型并绑定场景路由。

DeepSeek 官方供应商可点「余额」查账户余量；Key 失效或余额不足会导致场景路由报无可用模型。

  1. 1
    新增供应商点击「+ 新增」，填写标识名（如 deepseek）、展示名、协议类型
  2. 2
    选上游预设OpenAI 兼容协议下可选 DeepSeek、通义等预设，自动填充 Base URL 与默认模型
  3. 3
    填写凭证API Key（或多 Key 每行一个）；Codex 类供应商按页内指引配置 OAuth
  4. 4
    保存并探测保存后点「连通」验 Key →「拨测」发真实请求 →「测试」快速对话；均通过再「启用」
  5. 5
    注册模型列表行点「模型」或进入模型管理，模型 ID 须与供应商控制台一致
标识名 name必填英文唯一，场景路由中引用；创建后不可改
协议 type必填多数选 OpenAI 兼容；特殊供应商按页内类型选择
Base URL必填上游 API 地址；选预设后通常自动填充
API Key必填sk- 开头密钥；支持多 Key 轮询
默认模型供应商级兜底 model ID；可在模型管理中细化保存后务必做连通/拨测
优先级 / 权重多供应商并存时的调度参数（一般保持默认即可）

区域配置

  • AI 供应商与模型为全站共用
  • 配额规则、部分 Prompt 可按区域或用户等级区分

验证是否生效

  • 完成供应商 → 模型 → 场景路由三步
  • AI 对话能正常回复
  • 官方机器人或智能评论开启 AI 后，用量与日志有记录

常见问题

场景路由保存后仍报无可用模型模型 ID 与供应商控制台不一致；Key 失效或余额不足。
侧栏没有 AI中台模块未开通或账号无菜单权限。
回复内容违规或为空查看风险审核；调整 Prompt 模板或供应商审核策略。
