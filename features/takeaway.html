外卖 ​

按区域开启外卖、审核商家、维护商品，并管理订单与派单。

按区域开启外卖、审核商家、维护商品，并管理订单与派单。与服务表单（跑腿）共用骑手池，但区域配置相互独立。

商户管理 → 外卖外卖
  • 外卖模块已授权（我的模块）
  • 高德地图 Web Key + 安全密钥
  • 微信支付等
  • 有可用骑手（派单需要，见骑手文档）

建议顺序

  1. 1
    区域外卖配置商户管理 → 外卖 → 区域外卖配置：开区域、配送范围、派单策略
  2. 2
    佣金配置商户管理 → 外卖 → 佣金配置：平台抽成规则
  3. 3
    商家入驻商家审核 → 商家管理：通过测试店并设为营业
  4. 4
    商品维护商品分类 / 商品管理 / 规格小料
  5. 5
    骑手与联调骑手审核通过测试骑手后，下测试单观察外卖订单派单

菜单位置与「内测中」

外卖相关菜单在「商户管理 → 外卖」下。若侧栏「商户管理」或其子菜单显示「内测中」，表示产品功能尚未对全部站点开放，即使已在「我的模块」授权也可能暂时无法进入，请联系交付方。

区域外卖配置

商户管理 → 外卖 → 区域外卖配置必填按区域开关与配送规则
是否开通外卖总开关
配送范围 / 起送价 / 配送费直接影响能否下单与费用
派单策略自动派单/抢单、超时转派等
营业时段非营业时间不可下单

商家与商品

商户管理 → 外卖 → 商家审核处理入驻申请
商户管理 → 外卖 → 商家管理营业状态、店铺信息
商品分类 / 商品管理 / 规格小料菜单维护
桌码管理堂食扫码点餐（若启用）

订单与收益

商户管理 → 外卖 → 外卖订单查单、处理异常
商户管理 → 外卖 → 平台收益平台佣金收入

与跑腿、骑手的关系

  • 区域外卖配置与服务表单配置相互独立，可只开外卖
  • 派单共用骑手池：须先在「商户管理 → 骑手」审核通过骑手
  • 服务表单（跑腿）入口与配置见跑腿文档，不在本分组下

验证是否生效

  • 测试区域外卖已启用，一家测试店审核通过并营业
  • 客户端能进店、加购、支付；外卖订单出现新单

常见问题

用户看不到外卖区域未启用；UI 无入口；不在配送范围。
长时间无人接单骑手是否在线；派单策略是否过严。
