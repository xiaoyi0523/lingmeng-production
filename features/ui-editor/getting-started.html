快速上手 ​

本篇带您完成 第一次页面设计：从进入编辑器到客户端看到效果。

第一步：进入页面配置 ​

  1. 浏览器打开管理后台（见 进入管理后台）
  2. 左侧菜单 → UI管理 → 页面配置
  3. 顶部 区域 筛选：首次建议选 平台默认，作为全站兜底

第二步：新建或编辑页面 ​

新建 ​

  1. 点击右上角 + 新建页面
  2. 选择页面类型（见 页面类型说明）
  3. 填写页面名称
  4. 点击 创建并编辑（面板类页面为 进入配置）

编辑已有页面 ​

在卡片上点击 设计（面板类为 配置）。

左侧可按类型筛选：应用首页、功能页面、自定义页面、社区圈子等。

第三步：添加组件 ​

  1. 在 左侧组件库 展开分类，点击某个组件（如「轮播图」）
  2. 组件会插入 中间手机画布，并自动选中
  3. 在 右侧属性面板 修改内容（如上传轮播图片）
  4. 切换到 样式 Tab 调整间距、圆角等

调整顺序 ​

  • 选中组件后，使用节点操作菜单 上移 / 下移 / 复制 / 删除
  • 列表类组件（笔记列表等）建议放在页面 靠下位置

推荐首页结构 ​

text
轮播图 / 顶部图
  ↓
金刚区 / 搜索栏
  ↓
筛选标签（可选，与下方列表联动）
  ↓
话题气泡 / 榜单 / 双卡行动 等运营模块
  ↓
笔记列表 或 圈子列表 或 瀑布流（三选一）
  ↓
结束文本（可选，作为列表页脚）

第四步：配置页面级设置 ​

在画布上 点击空白处（不选中任何组件），右侧显示 页面配置：

  • 页面背景色、顶部背景图
  • 导航栏标题、样式（默认 / 胶囊 / 自定义 / 隐藏）
  • 分享标题与封面（部分页面）

详见 编辑器界面说明。

第五步：保存 ​

工具栏点击 保存：

  • 可选择是否 同时更新封面截图（用于页面列表缩略图）
  • 保存后写入服务器，但 尚未对用户生效

第六步：启用（发布） ​

返回 页面配置列表：

  1. 找到刚保存的页面卡片
  2. 若状态为 禁用，点击 启用
  3. 同区域、同页面类型下，其它版本会自动变为禁用

必须启用

仅「保存」不会切换线上版本；用户端拉取的是 启用中 的那一条配置。

第七步：客户端验证 ​

  1. 确认客户端当前 区域 与编辑区域一致
  2. 杀进程重进 App，或在首页 下拉刷新
  3. 检查修改的模块是否已更新

Tab 页（首页、发现）有本地缓存，若未更新可稍等或清除缓存。

配置 TabBar（可选） ​

底部导航在独立页面配置：

UI管理 → TabBar配置 → 选择区域 → 编辑 Tab 项 → 保存配置

详见 TabBar 配置。

多区域复制技巧 ​

  1. 先在 平台默认 做好一套完整 UI
  2. 切换到目标区域 → 新建页面 选同类型
  3. 或在列表对已有配置 复制，再微调
  4. 启用该区域版本
