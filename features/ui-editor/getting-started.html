快速上手 ​

本篇带您完成第一次页面设计：从进入编辑器到客户端看到效果。

本篇带您完成第一次页面设计：从进入编辑器到客户端看到效果。

UI管理 → 页面配置UI 编辑器

建议顺序

  1. 1
    进入页面配置UI管理 → 页面配置，选择区域（首次建议平台默认）
  2. 2
    新建或编辑页面选择页面类型，创建并进入设计
  3. 3
    添加组件左侧组件库点击添加，右侧属性/样式调整
  4. 4
    保存工具栏保存（尚未对用户生效）
  5. 5
    启用返回列表点击启用（必须启用才切换线上版本）
  6. 6
    客户端验证确认区域一致，杀进程重进或下拉刷新
推荐首页结构
轮播图 → 金刚区/搜索栏 → 筛选标签 → 运营模块 → 笔记列表/圈子列表/瀑布流 → 结束文本
页面级设置点击画布空白处，右侧显示页面配置：背景色、导航栏标题与样式、分享标题与封面等。
