编辑器界面说明 ​

路径：UI管理 → 页面配置 → 进入某页面的 设计 界面。

认识 UI 编辑器界面：左边选组件、中间手机预览、右边改属性。改完记得「保存」再在列表里「启用」——只保存不等于用户能看到。

UI管理 → 页面配置 → 设计·运营 / UI 编辑人员pages_admin/ui-editor/list
  • 侧栏可见 UI管理（我的模块已开通 UI 配置）
  • 用电脑浏览器打开管理后台（Chrome / Edge 体验最佳）
  • 已在页面配置列表选好要编辑的区域

建议顺序

  1. 1
    进列表UI管理 → 页面配置，顶部选好区域
  2. 2
    进设计目标页面点「设计」或「配置」
  3. 3
    编辑保存拖组件、改属性后顶栏点「保存」
  4. 4
    启用返回列表点「启用」，用户端才切换线上版本
  5. 5
    验收App 切换到相同区域，杀进程重进或下拉刷新

保存 ≠ 启用

顶栏「保存」只把草稿写到服务器；列表里绿色「启用」才决定用户看到哪一条。

工具栏「预览」只是截图，不是发布。最终以 App 内效果为准。

和 TabBar 是两套配置

底栏几个 Tab、图标、跳转在「TabBar配置」单独保存；本页只管 Tab 点进去后的页面内容。两边都要各自保存。

左侧组件库

  • 组件按 6 大类折叠：基础元素、布局导航、信息展示、社区内容、运营模块、表单/服务
  • 灰色不可点的组件表示当前页面类型不允许使用（例如首页不能添加表单组件）
  • 圈子页左侧还会出现头区布局、笔记卡片模板等圈子专属配置项，不属于画布组件

页面配置列表（进编辑器前）

路径：UI管理 → 页面配置。所有「保存」和「启用」都在这里收尾。

列表顶部的区域筛选 = 你正在管哪一层。客户端用户属于哪个校区，就要启用那个校区的配置（没单独配则继承全平台）。

封面图保存时可选生成的截图；没图会显示占位或结构示意
类型标签应用首页、功能页、自定义页等 —— 决定能拖哪些组件
状态绿色「启用」= 用户正在看这条；灰色「禁用」= 草稿或历史版本
设计 / 配置画布类页面进「设计」；个人中心、消息等面板页进「配置」
启用点一下切换线上版本；同区域同类型通常只能启用一条（自定义页、服务表单可多条）
复制整份复制成新草稿，方便做 v2 再启用
删除删掉这条配置，启用中的请先换启用别的再删

导入导出使用场景

导入会覆盖当前画布全部内容，操作前请确认或先导出备份。

测试 → 生产测试环境导出 JSON，生产环境同类型页面导入
备份重大改版前导出一份 JSON 存档
多区域复用平台默认导出 → 目标区域新建同类型 → 导入 → 微调 → 启用

验收清单

  • 顶栏保存成功，列表封面图已更新（若勾选）
  • 列表页该配置状态为「启用」
  • 客户端区域与编辑时选择的区域一致
  • App 内页面内容与编辑器画布一致

常见问题

保存了但 App 没变化列表是否已启用；客户端区域是否与编辑区域一致；Tab 页有缓存可杀进程重进。
组件是灰色的点不了当前页面类型不允许该组件，见页面类型说明。
改了 TabBar 首页内容没变正常。首页内容在页面配置编辑，不是 TabBar。
导入 JSON 后想恢复导入前应先导出备份；导入会覆盖当前画布全部内容。
全平台和校区配置关系校区未单独配置时继承全平台；校区启用自己的配置后覆盖全平台。
