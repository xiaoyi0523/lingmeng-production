UI 编辑器常见问题 ​

保存不生效、组件灰色、筛选联动、TabBar 与页面配置分离等常见问题的排查指引。

UI 编辑器运营常见困惑：保存不生效、区域搞错、组件置灰、筛选不联动、TabBar 与页面分离、导入覆盖等。

UI管理UI 编辑器

保存成功但 App 里没变化

  • 列表页该配置是否已启用（绿色状态）— 仅保存不会切换线上版本
  • 客户端区域是否与编辑区域一致（平台默认 vs 具体校区）
  • 杀进程重进或下拉刷新；Tab 页有缓存
  • 是否改错了页面类型（改的是功能页，却在看首页 Tab）

侧栏没有 UI管理

  • 系统设置 → 我的模块 查看 UI 配置是否已开通
  • 系统设置 → 账号权限 是否为账号分配 UI 编辑权限

筛选标签切换后列表不刷新

  • 列表 section 与筛选标签的 filterLinkKey 是否完全一致（区分大小写）
  • 筛选标签「下方内容模式」是否为列表 API 联动（非 Tab 独立内容区）
  • 圈子页联动目标固定为笔记，不能选圈子列表
筛选联动详解文档

TabBar 与页面内容对不上

TabBar 与页面配置分开保存、分开启用：底栏样式与跳转 → TabBar配置；Tab 内画布内容 → 页面配置对应类型（home/feature 等）。

服务表单提交按钮不显示

  • 是否添加了提交底栏（每页唯一，固定吸底）
  • 是否在服务表单（errand_service）类型页面编辑
  • 页面是否已保存并在列表启用

常见问题（速查）

只保存了，用户端还是旧版须在页面配置列表点「启用」。同类型同区域同时只能有一条启用；保存 ≠ 上线。
平台默认改了，某校区没变该校区已有单独 UI 配置行，不会继承平台默认；切到该校区编辑或复制平台配置过去。
组件库某项是灰色当前页面类型不允许（如首页不能加表单组件）；或互斥已满（筛选标签/列表三选一）。见页面类型说明。
切换筛选 Tab 列表不动筛选标签与笔记/圈子列表的 filterLinkKey 须相同；模式须为 API 联动。
改了 TabBar 首页内容没变正常。首页内容由「页面配置 → 应用首页」控制；TabBar 只管底栏与 switchTab 路径。
Tab 点了空白或报错TabBar 跳转路径须对应已启用的页面；业务模块未开通时目标页可能为空。
导入 JSON 后布局乱了导入会覆盖当前画布全部内容；误操作请用导入前导出的备份 JSON 恢复。
图片上传了编辑器里不显示检查系统配置 → 文件存储是否保存且测试通过；URL 须公网可访问。
AI 生成按钮不可用AI 中台未开通或未配场景路由；运营可手搭或请管理员配 AI 中台。见 AI 面板文档。
预览和真机不一样工具栏预览为截图示意；数据组件（笔记列表等）线上才拉真实 API；以 App 内为准。
