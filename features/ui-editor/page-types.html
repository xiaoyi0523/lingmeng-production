页面类型说明 ​

在 UI管理 → 页面配置 中，每种 页面类型 对应客户端的不同位置，且 可用组件不同。

新建页面时要先选对类型：它决定页面出现在 App 哪、能拖哪些组件。类型选错，后面组件会变灰点不了。

UI管理 → 页面配置·运营 / UI 编辑人员pages_admin/ui-editor/list

建议顺序

  1. 1
    想清楚放哪底部 Tab？我的/消息面板？还是活动独立页？
  2. 2
    新建UI管理 → 页面配置 → + 新建页面，弹窗里选类型
  3. 3
    编辑并保存设计或配置完成后顶栏保存
  4. 4
    启用列表点启用；Tab 页还要确认 TabBar 已指向对应 Tab

保存、启用、区域（三条铁律）

TabBar 管底栏跳转，页面配置管 Tab 里内容 —— 两套菜单、两次保存，别只改一边。

保存存草稿，用户不一定看得到
启用同区域 + 同类型（如应用首页）通常只能启用一条；启用新的会自动禁用旧的
区域列表顶部选「全平台」或具体校区；没单独配的校区继承全平台已启用的那条

类型一览（后台显示名）

应用首页（home）底部第一个 Tab 的首页；三栏画布编辑
功能页面（feature）常用作发现/圈子广场；三栏画布，和首页组件规则相同
个人中心（profile）「我的」Tab 内；表单式配置页，按钮是「配置」
消息中心（news）消息 Tab；面板配置
设置中心（settings）设置列表分组；面板配置
用户引导（user_guidance）新用户引导步骤；面板配置
官网介绍（official_intro）全站介绍页；面板配置
自定义页面（custom）独立活动页，不占 Tab；需自己配入口跳转
社区圈子（forum）单个圈子详情；画布 + 左侧头区/卡片模板
服务表单（errand_service）跑腿等下单页；只能加表单类组件

Tab 页面（首页 & 功能页）

用户怎么进这两个 Tab？去 UI管理 → TabBar配置 设图标和跳转；页面里具体放什么组件，仍在本页面对应类型里编辑、保存、启用。

  • 应用首页：用户打开 App 默认看到的第一个 Tab，常配轮播 + 金刚区 + 筛选 + 笔记列表
  • 功能页面：第二个 Tab 常做发现/圈子广场；组件和首页一样多
  • 两者在页面配置里各有一条（或多条草稿），互不影响 —— 改首页不会自动改功能页

面板配置页（不进三栏画布）

个人中心、消息、设置等：列表卡片按钮是「配置」，打开后是专用表单，不是拖组件。

面板页也要：保存 → 回列表启用，用户端才切换。

个人中心头像区样式、功能卡片、菜单入口
消息中心消息 Tab 结构、订阅消息入口卡片
设置中心设置项分组与跳转
用户引导引导步骤文案与配图
官网介绍介绍页模块与文案

自定义页面

后台技术标识 page_type 新建时会自动生成（如 custom_xxx），配跳转时选对即可，不必背英文。

  • 独立页面，不占底部 Tab 位
  • 要从金刚区、按钮、TabBar、通知等配「点击动作」跳过来
  • 同区域可启用多条自定义页（靠不同 page_type 或入口带 page_config_id 区分）
  • 适合：活动页、专题页、静态介绍

社区圈子（forum）

圈子详情页 UI，包含头区配置与画布组件两部分。

画布仅可添加筛选标签 + 笔记列表（与首页相比，筛选联动目标固定为笔记）。

头区布局默认 / 居中 / 卡片 — 圈子顶部封面与信息排版
动态列表卡片模板模板 1 / 2 / 3 — 帖子展示样式
跟随首页是 / 否 — 列表样式是否与首页笔记列表一致

服务表单（errand_service）

  • 组件库仅显示表单/服务 16 个组件
  • 隐藏轮播、社区、榜单等内容组件
  • 必须包含提交底栏（每页唯一，固定吸底）
  • 右侧额外服务表单 Tab：履约模式、计价公式、模板编码等

各类型可用组件对照

home / feature / custom基础元素 ✅（按钮在表单页隐藏）；布局导航 ✅；信息展示 ✅；社区内容 ✅；运营模块 ✅；表单/服务 ❌
forum基础元素 ✅；布局导航仅筛选标签；信息展示 ✅；社区内容仅笔记列表；运营模块 ❌；表单/服务 ❌
errand_service仅表单/服务全部可用；其他分类 ❌

互斥与唯一性规则

以下规则在编辑器中自动限制（重复添加会提示或置灰）。

筛选标签每页最多 1 个
圈子列表 / 笔记列表 / 瀑布流三选一，每页最多 1 个
提交底栏服务表单页最多 1 个
表单组件仅服务表单页可添加

和 TabBar 怎么配合

一句话：TabBar 决定「底栏有几个坑、点坑跳哪」；页面配置决定「跳进坑之后看到什么」。
  • UI管理 → TabBar配置：显示/隐藏底栏、最多 5 个导航项、图标文字、跳转方式（Tab 页要选 switchTab）
  • UI管理 → 页面配置：编辑 home / feature / news / profile 等类型的实际内容
  • 两边按区域分别存；改 Tab 文案去 TabBar，改首页轮播去页面配置里的应用首页
  • 典型流程：TabBar 第二个 Tab 指向功能页 → 页面配置里编辑「功能页面」→ 两边各自保存 → 页面配置那条要启用

验收清单

  • 新建时类型与业务场景一致（别把活动页建成服务表单）
  • 目标区域列表里已启用对应类型配置
  • Tab 类页面：TabBar 对应项已保存且跳转方式正确
  • 自定义页：至少一个入口（金刚区/按钮）已配跳转
  • 客户端切到同区域，杀进程重进后页面与后台一致

常见问题

组件全是灰色页面类型不对：服务表单只能加表单组件；圈子页不能加轮播等。
启用首页后功能页变了不会联动；检查是否误启用错类型或区域。
Tab 点了空白页TabBar 路径错，或该类型页面未启用。
新校区看不到首页该校区没单独配置时会继承全平台；若仍空白，查全平台是否已启用首页。
自定义页不知道跳哪在按钮/金刚区「点击动作」里选自定义页，或让实施提供 page_type。
