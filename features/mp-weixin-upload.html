小程序上传 ​

路径：系统设置 → 小程序上传

小程序发行包随灵萌服务端内置，无需单独上传 zip。只需配置微信上传密钥，在后台一键预览、一键上传到微信，不用在自己电脑上装微信开发者工具。这里管「发版上传」；用户登录用的 AppID 仍在 系统配置 → 微信小程序 里配置。

注意：预览与上传会在服务器上编译处理小程序，较占用 CPU 与内存，可能影响同期在线用户。请尽量在业务低峰、少人在线时操作（如深夜或清晨）。

平台托管小程序发版：小程序包随服务端内置，上传密钥后在后台一键预览、一键提交到微信，无需在本机安装微信开发者工具。

系统设置 → 小程序上传·站点运营 / 发版负责人
  • 已在微信公众平台下载「代码上传密钥」
  • 账号具备小程序上传写权限（mp.weixin.upload:write 或 update）
  • 服务器 Node.js 版本 22–24，且运行状态页各项显示就绪

这个功能是做什么的

把发版动作放到灵萌服务器上完成，运营在后台点几下即可。

预览、上传会在服务器上编译处理小程序，CPU 与内存占用较高，可能拖慢同期正在使用的管理后台与用户访问。请尽量在业务低峰、少人在线时操作（如深夜或清晨），避免上课/活动高峰发版。

  • 小程序发行包（mp-weixin.zip）随灵萌服务端内置，部署/更新后端后自动同步，无需运营上传
  • 只需上传微信代码上传密钥，由平台代为连接微信并完成预览/上传
  • 可先「预览」生成二维码，手机扫码确认无误后再「上传到微信」
  • 不用每位运营人员本机安装微信开发者工具

和「微信小程序配置」别搞混

系统设置 → 系统配置 → 微信小程序 Tab填 AppID、AppSecret，测 Token；决定用户能不能微信登录
系统设置 → 小程序上传上传密钥、预览/上传到微信；决定线上小程序版本（发行包随服务端内置）

页面怎么用（五个分区）

运行状态查看内置小程序包、密钥、CI 上传工具、Node/npm 是否就绪；红色提示按说明逐项处理
资源文件上传密钥、可换小程序 Logo；首次需点「安装上传工具」
编译设置填 AppID、版本号、备注（更新说明）、CI 机器人编号；可按需开关压缩选项
预览上传「预览」出二维码扫码体验；「上传到微信」提交到微信公众平台
运行日志查看安装、预览、上传过程进度与输出

推荐操作顺序

  1. 1
    拿上传密钥登录微信公众平台 → 开发管理 → 开发设置 → 小程序代码上传 → 生成并下载密钥（妥善保管）
  2. 2
    看运行状态打开本页「运行状态」Tab，确认内置 mp-weixin.zip、密钥、上传工具、Node 均就绪
  3. 3
    上传密钥「资源文件」→ 上传密钥；首次点击「安装上传工具」等待完成；可选替换 Logo
  4. 4
    填版本信息「编译设置」→ AppID、版本号（如 2.0.0）、备注 → 保存设置
  5. 5
    先预览再上传「预览上传」→ 预览扫码确认 → 再点「上传到微信」（建议低峰时段）
  6. 6
    微信后台收尾登录微信公众平台 → 版本管理 → 设为体验版或提交审核；若尚未登记，在 设置 → 功能设置 填写订单中心 path：pages_user/payment/orders

资源文件说明

上传密钥等同于发版权限，请勿外泄；泄露后请立即在微信公众平台重置并重新上传。

小程序发行包mp-weixin.zip 随灵萌服务端内置，部署或更新后端后自动写入运行目录，无需运营上传
上传密钥微信公众平台下载的代码上传密钥文件，仅用于向微信提交版本
替换 Logo可选；上传后会自动处理为小程序可用图标
安装上传工具首次发版必点一次；由平台在服务器安装 miniprogram-ci，按页内进度等待即可

编译设置说明

AppID与「系统配置 → 微信小程序 Tab」里填写的一致
版本号本次提交到微信的版本号，建议与发版说明一致（如 2.0.0）
备注上传时在微信后台显示的更新说明，方便区分各次提交
CI 机器人一般填 1 即可；多团队同时上传时可按微信文档区分编号
压缩与编译选项保持默认即可；特殊需求按灵萌实施指导调整

怎么确认成功了

  • 运行状态里内置 mp-weixin.zip、密钥、上传工具、Node 均显示已就绪
  • 预览能出现二维码，微信扫码可打开小程序
  • 上传完成后微信公众平台「版本管理」出现新版本
  • 体验版验证主要功能正常后，再提交审核或发布

常见问题

预览/上传按钮点不了看运行状态哪一项未就绪；Node 是否 22–24；密钥是否已传；是否已安装上传工具；内置 mp-weixin.zip 是否显示就绪；账号是否有上传权限。
发版时网站变慢正常吗正常。服务器编译上传较耗资源，请改在少人在线的时段操作，完成后再观察是否恢复。
还要不要装微信开发者工具一般不需要。平台托管上传即可；只有需要本地改代码时才用开发者工具。
小程序包需要手动上传吗不需要。mp-weixin.zip 随灵萌服务端内置，更新后端后会自动同步到运行目录；运营只需上传微信代码上传密钥。
和系统配置里填 AppID 有什么关系AppID 两处都要一致：配置页管登录，上传页管发版；上传密钥与登录 AppSecret 不是同一个东西。
密钥丢了或泄露微信公众平台重置上传密钥，然后在本页重新上传新密钥文件。
