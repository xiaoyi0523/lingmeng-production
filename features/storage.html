文件存储 ​

功能说明 ​

配置用户上传的图片、视频等文件的保存位置，支持服务器本地或主流云对象存储。

前置条件 ​

  • 若选云存储：已在对应云厂商创建 Bucket，并获取访问密钥。
  • 站点 系统配置 读写权限。
  • 视频水印功能额外要求服务器安装 ffmpeg（见系统配置 视频水印 Tab）。

管理后台配置步骤 ​

路径：系统设置 → 系统配置 → 文件存储 Tab

本地存储（local） ​

特点说明
适用小规模部署、内网测试
注意文件保存在应用服务器磁盘，需自行备份与扩容
访问通过站点域名下的静态路径访问，依赖反向代理配置

选择 local 后保存即可；确保服务器磁盘空间充足。

云存储 ​

支持 腾讯云 COS、阿里云 OSS、七牛云 等（以页面实际选项为准）。

通常需填写说明
存储类型选择对应云厂商
AccessKey / SecretKey云账号 API 密钥
Bucket 名称存储桶
地域 / Endpoint与 Bucket 所在区域一致
自定义域名（可选）CDN 加速域名

TIP

页面若提供「本地备份」选项，可在云存储为主的同时保留一份本地副本，便于迁移；按实际磁盘情况决定是否开启。

区域配置 ​

文件存储为 全站统一 配置，不按区域区分。各区域可在 笔记配置、用户配置 中限制上传格式与大小，但物理存储位置共用同一套参数。

相关菜单：

  • 系统设置 → 系统配置 → 功能与上传：全站允许的后缀、单文件大小上限
  • 区域管理 → 笔记配置：笔记是否允许图片/视频等

验证是否生效 ​

  1. 在客户端发布带图笔记或更换头像，上传进度正常且图片可访问。
  2. 系统设置 → 文件管理 中能看到新上传记录（如有该菜单权限）。
  3. 若使用云存储：登录云控制台，对应 Bucket 中出现新对象。

常见问题 ​

上传失败或 413

  • 检查 功能与上传 中大小限制与 Nginx client_max_body_size 是否一致。
  • 云存储密钥、Bucket 名称、地域是否匹配。

图片链接打不开

  • local 模式：确认静态文件目录已挂载并可公网访问。
  • 云模式：检查 Bucket 读权限、CDN 域名是否 HTTPS 且未过期。

切换存储方式后旧图失效

  • 历史 URL 仍指向旧位置；迁移需运维协助批量同步文件，或保留旧存储只读一段时间。
