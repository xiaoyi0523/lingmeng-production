抽奖活动 ​

功能说明 ​

创建与管理平台抽奖活动，配置奖品、开奖规则，并审核中奖记录。

前置条件 ​

  • 抽奖模块已在授权中开通。
  • 若活动需付费参与或奖品涉及余额 / 支付，须配置 支付与提现。
  • 具备 平台推广 → 抽奖管理 访问权限。

管理后台配置步骤 ​

路径：平台推广 → 抽奖管理

典型操作流程：

  1. 新建活动 — 填写名称、时间、参与条件、奖品设置
  2. 发布 — 使活动在客户端可见（以页面状态流转为准）
  3. 监控参与 — 列表查看参与人数、奖池消耗
  4. 中奖处理 — 审核或确认中奖用户，安排发奖
  5. 结束 / 下架 — 到期后关闭入口

奖品类型可能包括：积分、余额、实物、优惠券等，以创建表单选项为准。

区域配置 ​

抽奖活动创建时可绑定 适用区域 或全站（以创建页字段为准）。仅绑定区域的用户可见并参与。

区域级推广、补贴规则与 优惠券与推广 独立；抽奖不参与推广员分佣 unless 业务另行配置。

验证是否生效 ​

  1. 创建测试抽奖，时间设为当前有效，奖品为少量积分。
  2. 客户端在对应区域看到活动入口，成功参与一次。
  3. 抽奖管理 列表参与数增加；若即时开奖，中奖记录出现且用户积分 / 余额变动可在 积分流水 / 余额流水 中核对。

常见问题 ​

客户端没有抽奖入口

  • 活动未发布或已过期。
  • 用户所在区域不在活动范围。
  • UI管理 未配置展示入口。

开奖异常或重复中奖

  • 检查活动规则中的每人限次、总名额。
  • 在列表中找到活动查看异常状态，必要时手动下架。

实物奖品如何发放

  • 在 抽奖管理 中记录中奖用户信息，线下发货后在后台标记完成（以页面操作为准）。
