推广员体系 ​

路径：平台推广 → 推广员

通过邀请关系拉新，并按规则发放余额/积分奖励。规则按区域配置。

前置条件 ​

  • 推广相关模块已开通（系统设置 → 我的模块）
  • 已创建目标区域（区域管理 → 区域列表）
  • 若奖励发到余额，确认 支付与资金 / 账本可用

一、推广配置（必做） ​

路径：平台推广 → 推广员 → 推广配置

  1. 选择区域（或平台默认）
  2. 打开 启用推广（总开关；关闭后注册/登录不会完成绑定发奖）
  3. 按运营模式选择：
    • 仅推广员：需先通过推广员审核，再邀请
    • 全员推广模式：普通用户也可邀请（页面会显示「全员推广」chip）
  4. 填写奖励：
    • 推广员邀请奖励：邀请人 / 被邀请人 · 余额或积分
    • 全员推广奖励（若开启全员模式）
  5. 注册后绑定天数：超过天数未绑定则失效；填 0 表示不限制
  6. 资金策略（如有）：
    • 使用负责人账户发奖
    • 负责人不足时跳过发奖
  7. 配置推广默认标题、封面（分享用）
  8. 点 保存配置

页面状态 chip 会显示：推广已启用/关闭、全员推广/仅推广员、是否继承平台默认。

区域继承

区域编号 0 为平台默认。未单独配置的区域继承平台行。需要某校区单独奖励时，为该区域新建/编辑一行。

二、推广员审核 ​

路径：平台推广 → 推广员 → 推广员审核

  1. 用户在客户端提交推广员申请（入口以 UI 配置为准）
  2. 后台审核通过 / 拒绝
  3. 通过后该用户可按「仅推广员」模式邀请他人

三、邀请记录 ​

路径：平台推广 → 推广员 → 邀请记录

查看邀请关系、是否发奖成功，便于对账与客诉。

奖励入账可在 财务管理 → 余额流水 / 积分流水 核对。

验证是否生效 ​

  1. 测试区域 启用推广 并设小额奖励
  2. （仅推广员模式）审核通过一个测试推广员
  3. 用邀请链接注册新用户，在绑定天数内完成注册/登录
  4. 邀请记录 有关系；邀请人/被邀请人流水有奖励（按配置）

常见问题 ​

现象处理
邀请无奖励推广是否启用；是否超过绑定天数；负责人账户是否不足且开启了跳过
用户申请不了推广员UI 是否有入口；区域是否仅全员模式导致无需申请
侧栏无推广模块未开通或账号无权限
