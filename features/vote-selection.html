投票与评选活动 ​

功能说明 ​

按区域配置投票、评选活动的规则与权限，并管理前台发起的活动实例。

前置条件 ​

  • 目标区域已在 区域管理 → 区域列表 中创建。
  • 笔记 / 圈子等基础社交能力已正常使用。
  • 账号具备区域配置或活动管理相关权限。

管理后台配置步骤 ​

投票 ​

区域规则

路径：区域管理 → 投票配置

设置该区域是否开放投票、每人可投次数、是否允许匿名、审核要求等（以页面字段为准）。

活动实例

路径：社交圈子 → 话题管理 或客户端用户发起的投票活动（视产品入口而定）；后台可在 笔记管理 中关联下架违规投票内容。

评选活动 ​

区域规则

路径：区域管理 → 评选活动配置

配置评选开关、报名资格、作品类型、投票权重、审核流程等区域级策略。

活动实例

路径：社交圈子 → 评选活动

  • 创建平台级或区域级评选活动
  • 审核参赛作品、公布结果
  • 查看报名与投票数据

区域配置 ​

两类配置均在 区域管理 分组下，且 按区域独立：

菜单说明
投票配置控制该区域用户能否发起 / 参与投票
评选活动配置控制评选类活动的规则与门槛

未单独配置的区域继承 平台默认 行（在页面顶部切换「平台默认」编辑）。

验证是否生效 ​

  1. 在 投票配置 中开启目标区域投票功能。
  2. 客户端在该区域创建投票，其他用户可正常投票且次数受规则限制。
  3. 在 评选活动配置 开启后，社交圈子 → 评选活动 创建活动，用户可报名；后台审核通过后前台展示。

常见问题 ​

用户找不到投票入口

  • 确认 投票配置 已对该区域启用。
  • 检查 UI 页面配置 是否展示相关入口。

评选无法报名

  • 评选活动配置 中是否限制等级、实名或圈子成员资格。
  • 活动是否已过报名时间（在活动列表中查看状态）。

票数异常

  • 查看是否允许多次投票、是否开启防刷；必要时在 用户管理 处理异常账号。
