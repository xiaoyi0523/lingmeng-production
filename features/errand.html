跑腿 ​

跑腿有两条常见玩法：

  1. 标准跑腿区域配置（商户管理里的区域规则 + 订单）
  2. 可配置服务表单（UI 编辑器拖表单：帮取、代办、预约等，带计价公式）

两者都依赖地图与支付；派单通常与 骑手 共用。

菜单位置

跑腿相关菜单挂在 商户管理 → 外卖 分组下。该分组可能显示「内测中」，见 外卖。

前置条件 ​

  • 跑腿 / 相关模块已开通（我的模块）
  • 高德地图、支付 已配置
  • 若需骑手履约：完成 骑手 审核上线

玩法 A：跑腿区域配置 ​

1. 配置区域 ​

路径：商户管理 → 外卖 → 跑腿区域配置

为每个区域设置（字段以页面为准）：

方向说明
是否启用跑腿总开关
服务范围距离或边界
基础价 / 里程费 / 时段加价计价
物品类型、重量上限等下单约束

保存后，该区域用户端出现跑腿入口（还取决于 UI 是否配置入口）。

2. 跑腿订单 ​

路径：商户管理 → 外卖 → 跑腿订单

查看进行中/已完成订单，处理异常、取消、退款（需相应权限）。

与外卖订单分开：外卖看 外卖订单，跑腿看 跑腿订单。

玩法 B：可配置服务表单（推荐做特色业务） ​

适合：帮取快递、代办登记、预约服务等——每种服务一张表单页，运营可自己改字段和计价。

步骤 ​

  1. 打开 UI管理 → 页面配置
  2. 新建 页面，类型选 服务表单
  3. 进入 设计：从左侧只添加「表单/服务」类组件（输入、地址、选项、提交底栏等）
  4. 点击画布空白，在右侧 服务表单 Tab 配置：履约方式、基础价、计价方式/公式
  5. 必须包含 提交底栏（每页唯一）
  6. 保存 → 在列表中 启用
  7. 用金刚区/按钮等配置 点击动作 跳到该页（见 样式与点击动作）

完整组件说明：表单/服务组件
上手：UI 编辑器快速上手

保存启用后，系统会把表单同步为跑腿侧可用的服务模板（运营无需改代码）。

区域关系 ​

配置说明
跑腿区域配置标准跑腿按 region 独立开关与计价
区域外卖配置与跑腿相互独立，可只开其一
服务表单页也可按区域保存页面配置

地图 Key 全站共用；范围与价格按区域/页面分别填。

验证是否生效 ​

标准跑腿 ​

  1. 区域配置已启用并设简单计价
  2. 客户端能填写取送地址、算出费用并支付
  3. 跑腿订单 出现新单；骑手可接单流转

服务表单 ​

  1. 页面已启用，入口跳转正确
  2. 必填项校验生效，价格随选项变化（若配了加价）
  3. 提交并支付成功，后台能查到对应订单/单据

常见问题 ​

现象处理
没有跑腿入口区域未启用；UI 未配入口；模块未开
费用为 0 或算不出地图 Key；起终点超范围；计价公式未配
无人接单与外卖相同，检查骑手在线与派单
服务表单组件是灰的页面类型不是「服务表单」
