微信支付（完整配置手册） ​

从微信商户平台到灵萌管理后台到客户端验收，逐步说明如何开通微信支付、配置回调、处理提现打款。

从微信商户平台到灵萌管理后台到客户端验收，逐步说明如何开通微信支付、配置回调、处理提现打款。

系统设置 → 系统配置 → 微信支付 Tab微信支付
  • 站点 HTTPS 已配置，域名与网站信息一致
  • 支付模块已在系统设置 → 我的模块中开通（否则 Tab 显示未解锁）
  • 小程序 AppID 已在商户平台与商户号绑定
  • 账号具备系统配置读写权限

建议顺序

  1. 1
    商户平台注册商户号、绑定 AppID、申请证书与 APIv3 密钥
  2. 2
    配置回调在微信商户平台将支付通知 URL 设为 https://你的域名/api/payment/wx-notify
  3. 3
    灵萌后台系统设置 → 系统配置 → 微信支付 Tab：填写商户号、密钥、证书并保存
  4. 4
    验收0.01 元测试单 + 可选提现打款测试

微信商户平台操作

AppID 与商户号必须完成关联，否则客户端无法调起支付。

商户号必填账户中心 → 商户信息，10 位数字
绑定 AppID必填产品中心 → AppID账号管理 → 关联AppID
APIv3 密钥必填账户中心 → API安全 → 设置APIv3密钥
API 证书必填apiclient_cert.pem / apiclient_key.pem + 证书序列号
支付回调 URL必填https://你的域名/api/payment/wx-notify（在商户平台配置，不在灵萌后台填写）

灵萌后台填写（逐字段）

路径：系统设置 → 系统配置 → 微信支付 Tab → 保存设置。
商户号必填商户平台 10 位商户号
支付密钥必填APIv3 密钥
v3 证书序列号必填证书管理页序列号
支付公钥 ID商户平台公钥模式下的公钥 ID（若使用平台公钥验签）
CERT 证书 / KEY 密钥 / 支付公钥必填完整 PEM 内容，保留 BEGIN/END 行
转账场景 ID商家转账到零钱场景 ID（财务管理自动打款必填）

与小程序配置的关联

有「选购—下单—支付」能力的小程序须登记订单中心 path，否则代码提审可能被拒。也可在版本管理 → 提交审核时通过 order_path 参数填写；未登录用户扫码进入须能引导登录并回到订单页。

  • 系统设置 → 系统配置 → 微信小程序 Tab：AppID/Secret 与 Token 测试通过
  • 微信商户平台 AppID 已关联同一小程序 AppID
  • 小程序后台 request 合法域名含 API 域名
  • 微信公众平台 → 设置 → 功能设置 → 小程序订单中心 path：填写 pages_user/payment/orders（灵萌统一订单页；仅填主 path，不带参数与开头斜杠）

提现与打款

自动打款依赖转账场景 ID、API 证书及商户「商家转账到零钱」产品已开通。

财务管理 → 提现处理审核通过/拒绝用户提现申请
财务管理 → 资金交易查看支付、退款、转账流水

完整验收 checklist

  • 我的模块中支付能力已开通，微信支付 Tab 可编辑
  • 商户号与 AppID 已在商户平台绑定
  • APIv3 密钥、证书序列号、CERT、KEY 已填入并保存
  • 回调 URL 已在商户平台配置且外网可达
  • 微信公众平台已设置订单中心 path 为 pages_user/payment/orders
  • 0.01 元测试支付成功，财务管理 → 资金交易有 SUCCESS 记录
  • （若启用）小额提现审核通过后微信零钱到账

故障排查

支付页提示未配置支付模块是否开通 → 微信支付 Tab 必填项是否保存 → 商户号是否填写。
已付款仍待支付商户平台回调 URL 是否正确 → 证书/公钥是否匹配 → Nginx 反代勿缓存 POST body。
提现不到账转账场景 ID 是否填写 → 审核是否通过 → 商户转账产品是否开通 → 用户是否完成微信实名。
Tab 显示未解锁到系统设置 → 我的模块确认 payment 已开通。
