支付与提现 ​

微信支付详细手册

微信商户平台逐步操作、后台逐字段、回调、提现打款、故障排查请参阅：

👉 微信支付（完整配置手册）

功能说明 ​

配置微信支付、支付宝收单，处理用户提现申请，并为红包、转账、商城等业务提供支付能力。

前置条件 ​

  • 站点使用 HTTPS 正式域名，且与 系统设置 → 网站信息 一致。
  • 支付、提现相关能力已在授权中开通。
  • 已在微信商户平台 / 支付宝开放平台完成企业资质与应用创建。

管理后台配置步骤 ​

1. 微信支付 ​

详见 微信支付（完整配置手册）。

路径：系统设置 → 系统配置 → 微信支付 Tab

回调 URL：

text
https://你的域名/api/payment/wx-notify

2. 支付宝 ​

路径：系统设置 → 系统配置 → 支付宝 Tab

填写应用 AppID、应用私钥、支付宝公钥，并选择 生产 或 沙箱 环境。

支付宝开放平台回调 URL：

text
https://你的域名/api/payment/alipay-notify

在应用 网关设置 中配置上述地址。

3. 虚拟支付（可选） ​

路径：系统设置 → 系统配置 中 虚拟支付 Tab（若可见）

仅微信小程序内虚拟代币场景；需在小程序后台开通虚拟支付，并与商品配置对齐。

4. 提现处理 ​

路径：财务管理 → 提现处理

  • 查看用户提现申请列表
  • 审核通过 / 拒绝
  • 若已配置商户转账能力，系统可自动打款至微信零钱 / 支付宝

提现规则（最小金额、手续费等）在提现设置与 区域列表 相关字段中维护（以页面为准）。

5. 流水查询 ​

菜单作用
财务管理 → 资金交易支付、退款、转账流水
财务管理 → 余额流水用户余额变动
系统监控 → 对账中心异常订单对账（需权限）

区域配置 ​

提现费率、区域是否允许提现等，可在 区域管理 → 区域列表 编辑区域时设置（字段以页面为准）。

支付渠道本身为 全站统一 配置，不按区域区分商户号。

验证是否生效 ​

  1. 客户端发起一笔 0.01 元 测试支付（微信或支付宝），支付成功。
  2. 财务管理 → 资金交易 出现对应成功记录。
  3. 提交一笔测试提现，在 提现处理 中审核并完成打款（或确认自动打款到账）。
  4. 系统监控 → 系统状态 无持续「回调验签失败」类提示。

常见问题 ​

支付页打不开或提示未配置

  • 检查对应 Tab 必填项是否保存；授权是否含支付能力。
  • 小程序 AppID 是否与商户号绑定。

已付款订单仍显示待支付

  • 回调 URL 错误或外网不可达；证书 / 公钥与商户平台不一致。
  • 联系运维确认反向代理未缓存 POST body。

提现打款失败

  • 是否填写 转账场景 ID 并开通「商家转账到零钱」。
  • 用户是否完成实名与收款账号绑定。
  • 商户账户余额是否充足。

支付宝沙箱与生产混淆

  • 系统配置 → 支付宝 中「生产 / 沙箱」须与开放平台环境一致。
