地图与定位 ​

接入高德地图，为定位、距离筛选、外卖与跑腿派单等本地生活功能提供地理能力。

在系统配置中接入高德地图，为定位、距离筛选、外卖配送与服务表单（跑腿）等本地生活功能提供地理能力。

系统设置 → 系统配置 → 高德地图 Tab地图与定位
  • 高德开放平台已创建应用，并分别申请「Web 服务」与「Web 端（JS API）」类型 Key
  • 2021 年后创建的应用须为 JS API Key 配置安全密钥（securityJsCode）
  • 若使用外卖/服务表单，对应模块已在「我的模块」中开通

管理后台配置

路径：系统设置 → 系统配置 → 高德地图 Tab。须填写两类 Key，不可混用。

填写后点击「开始测试」验证 Key 类型；保存后无需重启，客户端下次加载地图时生效。

Key（原生）必填高德「Web 服务」类型 Key，供后端 POI 搜索、距离计算等
WebKey（JS API）必填高德「Web 端（JS API）」类型 Key，供 H5/小程序地图组件加载
安全密钥必填与 WebKey 同应用下的 securityJsCode（jscode）

与站点区域的关系

系统设置 → 系统配置 → 区域配置 Tab全站区域模式、默认距离限制（米）
区域管理 → 区域列表各区域中心点、半径等地理边界

业务侧区域配置（地图 Key 全站共用）

  • 地图 Key 为全站统一配置；配送半径、服务范围等业务参数按区域或页面单独维护。
商户管理 → 外卖 → 区域外卖配置外卖配送范围、起送价、派单策略等（商户管理分组可能显示「内测中」）
区域管理 → 服务表单配置跑腿/帮取帮送等服务表单的服务范围与计价（侧栏显示名即「服务表单配置」）
统一订单 → 服务表单订单查看服务表单类订单（含跑腿）

验证是否生效

  • 高德地图 Tab 点击「开始测试」，原生 Key 与 WebKey 均通过
  • 客户端带地图页面正常加载、可定位
  • 外卖：配送范围与距离计算合理（需区域外卖已启用）
  • 服务表单/跑腿：起终点解析正常，费用与距离匹配

常见问题

地图空白或报 INVALID_USER_KEYWebKey 须为 JS API 类型；安全密钥须与 WebKey 配对；原生 Key 须为 Web 服务类型，二者不可填反。
连接测试只通过一项两类 Key 用途不同，须在高德控制台分别创建对应类型后各填一项。
定位偏差大浏览器/小程序需用户授权位置；检查系统配置 → 区域配置中的距离限制是否过小。
外卖派单找不到骑手地图 Key 仅解决坐标；派单还依赖区域外卖配置、骑手在线状态与派单策略。
