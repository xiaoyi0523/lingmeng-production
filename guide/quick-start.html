本文面向站点运营方：您已从开发者或官方渠道拿到 Linux 安装包（lingmeng-x.x.x.zip），在 宝塔面板 上安装最新版 Go 并完成部署。

按顺序执行，不要跳步。

一、部署前准备 ​

项目说明
云服务器推荐 2 核 4G 及以上，系统 CentOS 7+ / Ubuntu 20.04+
宝塔面板已安装并可登录（宝塔官网 按系统版本安装）
安装包lingmeng-x.x.x.zip（内含可执行文件 lingmeng）
域名（生产）已备案，用于 HTTPS、微信回调
授权文件若开发者提供 license 相关文件，一并保存

二、在宝塔安装运行环境 ​

登录宝塔 → 软件商店，安装并启动：

软件版本建议用途
Go最新稳定版程序运行环境
MySQL8.0+业务数据库
Redis6.0+缓存、会话、队列
Nginx任意稳定版网站与 HTTPS

安装 Go 后，在宝塔 终端 执行 go version，确认输出为当前最新稳定版。

安装完成后，在 安全 中放行 80、443；不要对公网开放 8080（后端只在本机访问即可）。

可选（按需）： Meilisearch、Gorse 等见 可选基础设施。

三、创建 MySQL 数据库 ​

宝塔 → 数据库 → 添加数据库：

字段示例说明
数据库名lingmengv2自定，记住名称
用户名lingmeng与库名可相同
密码强密码向导里要填写
访问权限本地服务器默认即可

记下：数据库名、用户名、密码。Redis 若设置了密码，也一并记下（宝塔 Redis 设置里查看）。

四、上传并解压安装包 ​

  1. 宝塔 → 文件 → 进入 /www/wwwroot
  2. 新建目录 lingmeng（名称可自定，下文以此为例）
  3. 将 lingmeng-x.x.x.zip 上传到 /www/wwwroot/lingmeng
  4. 右键 zip → 解压，得到可执行文件 lingmeng
  5. 选中 lingmeng → 权限 → 勾选 执行，或终端执行：
bash
chmod +x /www/wwwroot/lingmeng/lingmeng

目录权限

运行后程序会在同目录生成 config.yaml、logs/、uploads/ 等，请保证 www 用户对该目录可写（宝塔默认站点目录一般已满足）。

五、用进程守护启动后端 ​

宝塔 → 软件商店 → 搜索安装 「进程守护管理器」（或 Supervisor）。

添加守护进程：

字段填写
名称lingmeng
启动用户root 或 www（与目录权限一致即可）
运行目录/www/wwwroot/lingmeng
启动命令/www/wwwroot/lingmeng/lingmeng
进程数量1

保存并 启动。首次启动会在运行目录生成 config.yaml，此时 setup_completed 应为 false。

在宝塔 安全 或服务器防火墙中，确认 8080 仅本机可访问（不对公网开放）。

六、添加网站与反向代理 ​

6.1 添加站点 ​

宝塔 → 网站 → 添加站点：

字段填写
域名campus.example.com（你的域名）
根目录可先用默认 /www/wwwroot/campus.example.com（仅占位，API 走反代）
PHP纯静态 或 不创建 PHP

6.2 配置反向代理 ​

进入该站点 → 反向代理 → 添加反向代理：

字段填写
代理名称lingmeng-api
目标 URLhttp://127.0.0.1:8080
发送域名$host

在代理配置中 开启 WebSocket（消息实时推送依赖 /api/ws）。

若宝塔版本需手写配置，在 配置文件 的 location / 中确保包含：

nginx
proxy_pass http://127.0.0.1:8080;
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
client_max_body_size 50m;

WebSocket 路径示例：

nginx
location /api/ws {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
}

6.3 配置 SSL（生产必做） ​

站点 → SSL → Let's Encrypt 申请证书并 开启强制 HTTPS。

微信/支付宝回调、初始化向导在生产环境 必须使用 HTTPS。

七、初始化向导（必做） ​

浏览器访问：

text
https://你的域名/setup

若尚未配置 SSL，可临时用 http://服务器IP:8080/setup（仅测试；生产请尽快上 HTTPS）。

按 初始化向导 逐步填写：

  1. 应用名、端口 8080、网站地址（填 https://你的域名，与宝塔站点一致）
  2. MySQL、Redis 连接信息 → 测试连接
  3. 生成 登录密钥
  4. 确认安装 → 等待建表 → 重启 进程守护中的 lingmeng

八、登录管理后台 ​

  1. 浏览器打开：https://你的域名/pages_admin/index/index
  2. 使用向导创建的管理员登录（常见默认 admin / admin123）
  3. 立即修改密码

→ 进入管理后台

顺序菜单文档

十、验证部署成功 ​

检查方法
后端进程宝塔进程守护中 lingmeng 状态为 运行中
API 存活访问 https://域名/api/health 或后台 系统监控 → 系统状态
管理后台能登录、能保存系统配置
文件上传网站信息里上传 Logo 成功
客户端小程序/H5 能打开首页（需单独发布客户端并配置合法域名）

常见问题 ​

进程启动后立即退出

  • 检查 lingmeng 是否有执行权限
  • 查看 /www/wwwroot/lingmeng/logs/ 下日志
  • 8080 端口是否被占用（宝塔 安全 或 netstat 排查）

反向代理 502

  • 进程守护是否运行中
  • 反代目标是否为 127.0.0.1:8080
  • 修改配置后 重载 Nginx

无法访问 /setup

  • 是否已完成安装（config.yaml 里 setup_completed: true 后不可重复安装）
  • 是否用了正确的域名与 HTTPS

更新版本

  • 在进程守护中 停止 服务 → 备份 config.yaml 与数据库 → 上传新版本 zip 覆盖 lingmeng 二进制 → 启动 服务（具体以开发者说明为准）
