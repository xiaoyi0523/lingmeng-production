快速部署 ​

面向站点运营方 · 安装包 lingmeng-x.x.x.zip · 推荐 2 核 4G 及以上 · 按顺序执行，不要跳步

1
云服务器CentOS 7+ / Ubuntu 20.04+ 推荐 2 核 4G
宝塔面板已安装并可登录
安装包lingmeng-x.x.x.zip
域名（生产）已备案，用于 HTTPS、微信回调
2
Go最新稳定版 终端 go version 确认
MySQL8.0+
Redis6.0+
Nginx任意稳定版
ffmpeg含 ffprobe 视频封面提取、整段视频水印依赖；图片水印不需要
  • 安全中放行 80、443；不要对公网开放 8080
  • 可选：Meilisearch、Gorse 见可选基础设施文档
  • ffmpeg 装好后：管理后台 → 系统设置 → 视频水印 →「服务端媒体依赖」→ 重新检测，应显示 ffmpeg / ffprobe 均已安装

宝塔 → 终端：安装 ffmpeg + ffprobe（按系统选一条执行）

# 方式一（推荐）：宝塔 → 软件商店 → 搜索「FFmpeg」→ 安装官方 FFmpeg 管理器

# 方式二：宝塔 → 终端，按系统选一条执行

# Ubuntu / Debian
apt update && apt install -y ffmpeg

# CentOS 7
yum install -y epel-release
yum install -y ffmpeg

# CentOS 8+ / Rocky / AlmaLinux
dnf install -y epel-release
dnf install -y ffmpeg --allowerasing

# 验证（两条都要有版本输出；ffprobe 随 ffmpeg 包一并提供）
ffmpeg -version
ffprobe -version
可选基础设施 →视频水印与服务端检测 →
3
MySQL 版本8.0 及以上 低于 8.0 可能导致迁移或 SQL 兼容问题
数据库名lingmengv2（自定）
访问权限本地服务器
  • 记下库名、用户名、密码，初始化向导中会用到
4
chmod +x /www/wwwroot/lingmeng/lingmeng

运行后会在同目录生成 config.yaml、logs/、uploads/，须保证 www 用户可写

5
运行目录/www/wwwroot/lingmeng
启动命令/www/wwwroot/lingmeng/lingmeng
进程数量1
  • 软件商店搜索「进程守护管理器」并安装（如图）
  • 首次启动生成 config.yaml，setup_completed 应为 false
  • 8080 仅本机可访问
6
  • 目标 URL：http://127.0.0.1:8080，发送域名 $host
  • 开启 WebSocket（消息推送依赖 /api/ws）
  • 生产必做：Let's Encrypt + 强制 HTTPS
proxy_pass http://127.0.0.1:8080;
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
client_max_body_size 50m;
7
  • 填写端口 8080、网站地址（与宝塔站点一致）
  • MySQL、Redis 连接信息 → 测试连接
  • 生成登录密钥 → 确认安装 → 重启进程

常见问题

进程启动后立即退出检查执行权限、logs/ 日志、8080 端口占用
反向代理 502进程守护是否运行、反代目标是否正确、重载 Nginx
无法访问 /setupsetup_completed 已为 true 不可重复；检查域名与 HTTPS
更新版本停止服务 → 备份 config.yaml 与数据库 → 覆盖二进制 → 启动
