本文从 空服务器 到 管理员能登录后台并完成首屏配置 的完整流程。按顺序执行，不要跳步。

一、服务器与软件要求 ​

软件版本用途
LinuxUbuntu 20.04+ / CentOS 7+ 等推荐
MySQL8.0+业务数据库
Redis6.0+缓存、会话、队列
Go1.21+（若源码运行）编译后端
Nginx任意稳定版反向代理、HTTPS（生产必装）

可选（按需 Docker 启动）：

组件用途
Meilisearch全文搜索
Gorse推荐系统

→ 可选基础设施

二、准备 MySQL ​

sql
CREATE DATABASE lingmengv2 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'lingmeng'@'%' IDENTIFIED BY '你的强密码';
GRANT ALL PRIVILEGES ON lingmengv2.* TO 'lingmeng'@'%';
FLUSH PRIVILEGES;

记下：主机、端口、3306、用户名、密码、库名。

三、获取代码并启动后端 ​

bash
# 上传或 git clone 到服务器
cd /opt/lingmeng

# 下载依赖
go mod download

# 首次启动（生成 config.yaml 模板）
go run ./src/cmd/server

首次运行后项目根目录出现 config.yaml，此时 setup_completed 应为 false。

本地调试

config.yaml 中设 app.env: local 可放宽部分限制。

生产建议： 用 systemd 或 Docker 守护进程，不要长期 go run 前台运行。

四、初始化向导（必做） ​

浏览器访问：

text
http://你的服务器IP:8080/setup

按 初始化向导 逐步填写：

  1. 应用名、端口 8080、网站地址（生产填 https://你的域名）
  2. MySQL、Redis 连接信息 → 测试连接
  3. 生成 登录密钥
  4. 确认安装 → 等待建表 → 重启服务

五、配置 Nginx + HTTPS（生产必做） ​

示例 Nginx 配置（替换域名与证书路径）：

nginx
server {
    listen 443 ssl http2;
    server_name campus.example.com;

    ssl_certificate     /etc/nginx/ssl/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/privkey.pem;

    client_max_body_size 50m;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket（消息实时推送）
    location /api/ws {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}

server {
    listen 80;
    server_name campus.example.com;
    return 301 https://$host$request_uri;
}

注意：

  • client_max_body_size 须 ≥ 系统配置 → 功能与上传 中的单文件上限
  • 微信/支付宝回调必须是 HTTPS 443

六、登录管理后台 ​

  1. H5 浏览器打开：https://你的域名/pages_admin/index/index
  2. 使用向导创建的管理员登录（默认可能是 admin / admin123）
  3. 立即修改密码

→ 进入管理后台
