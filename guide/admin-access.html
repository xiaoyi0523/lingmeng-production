进入管理后台 ​

访问地址 ​

管理后台为 H5 网页，请在电脑或手机浏览器中打开：

text
https://你的域名/pages_admin/index/index

仅支持 H5

管理后台不支持小程序内嵌打开，请使用 Chrome、Safari、Edge 等浏览器。

登录 ​

使用初始化向导中设置的超级管理员账号登录。

首次部署若未改密码，默认为 admin / admin123，登录后请立即修改。

界面说明 ​

┌─────────────┬──────────────────────────────────┐
│  左侧菜单    │  右侧工作区（列表/表单/配置 Tab）   │
│  （可折叠）  │                                   │
└─────────────┴──────────────────────────────────┘
区域作用
左侧菜单按业务分组：系统设置、区域管理、通知、AI、商户等
顶栏当前管理员、退出、主题切换
工作区具体配置表单或数据列表

菜单找不到某项？ ​

部分菜单需要功能已开通才会显示。请先到：

系统设置 → 我的模块

查看当前站点已开通的功能列表。未开通的菜单可能不显示或显示为灰色「未解锁」。

常用入口速查 ​

我想…菜单路径
配微信小程序/支付系统设置 → 系统配置
改网站名称 Logo系统设置 → 网站信息
新增校区/区域区域管理 → 区域列表
控制注册登录方式区域管理 → 用户配置
发通知、配模板通知控制台 → 事件模板
配 AI 对话AI 中台 → 供应商管理
改首页布局UI管理 → 页面配置 → UI 编辑器手册

完整 Tab 说明见 系统配置总览。

权限说明 ​

账号类型说明
超级管理员可见全部菜单
普通管理员按「账号权限」分配的菜单可见

分配权限：系统设置 → 账号权限 或 权限模板。
