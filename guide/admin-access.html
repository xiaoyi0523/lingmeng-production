进入管理后台 ​

访问地址 ​

管理后台为 H5 网页，请在电脑浏览器打开（推荐 Chrome / Edge）：

text
https://你的域名/pages_admin/index/index

仅支持 H5

不要在微信小程序里打开管理后台。手机浏览器可以应急，复杂配置（尤其 UI 编辑器）请用电脑。

登录 ​

使用初始化向导中设置的超级管理员账号。

首次部署若未改密码，默认为 admin / admin123，登录后请立即修改密码。

给同事开后台：见 账号权限与权限模板。

完整菜单说明见 后台菜单地图。

菜单找不到某项？ ​

按顺序检查：

  1. 系统设置 → 我的模块 — 功能是否已开通（说明）
  2. 系统设置 → 账号权限 — 当前账号是否勾了该菜单（说明）
  3. 是否显示 内测中 — 产品尚未对你站点开放，联系交付方
  4. 退出重新登录一次

WARNING

某区域已经建了专属配置，却把「启用」关掉，通常不会自动退回平台默认，而是直接拦截。详见 用户规则。
