初始化向导 ​

首次部署访问 /setup 完成一次性配置。 完成后写入 config.yaml、自动建表，该地址将不可用。

访问条件

地址https://你的域名/setup 或 IP:8080/setup
服务已启动宝塔进程守护中 lingmeng 已运行
未完成安装config.yaml 中 app.setup_completed 为 false

生产环境强烈建议先配置 SSL 再访问 setup。非 HTTPS 且非 localhost 时页面会提示风险。

向导步骤

共 5 步 · 点击展开详情

授权编号 形如 lic_xxx，从授权方获取
拉取密钥 授权站实例详情中复制
拉取授权文件 下载 license 到服务器
  • 编号和密钥请向授权方获取
项目名称 后台与日志显示名
网站端口 必填默认 8080，Go 进程监听端口须与 Nginx 反代端口一致
网站地址 必填完整 URL，如 https://campus.example.com须与微信回调、H5 域名完全一致
CORS 白名单 允许访问的前端地址，每行一个 Origin
  • 页面会实时校验当前访问域名与填写地址是否匹配
  • 独立 H5 域名、管理后台域名都要列入 CORS
https://campus.example.com
https://www.campus.example.com
MySQL 必填须提前创建空库，字符集必须 utf8mb4
Redis 必填多站点同 Redis 时缓存前缀必须不同
Meilisearch 可选，未部署 Docker 搜索服务则关闭容器约 0.5–1 GB
NebulaGraph 可选，社交图数据库，未部署则关闭容器约 2–3 GB
Gorse 可选，未部署则关闭容器约 6 GB（含内置 PostgreSQL/Redis）
  • 可选 Docker 栈全部启用合计约 8–10 GB（仅容器，不含 MySQL/Redis/Go 主程序）
  • 机器总内存 < 4 GB：不要安装可选 Docker 基础设施
  • 4–8 GB：仅按需启用 Meilisearch，关闭 NebulaGraph 与 Gorse
  • ≥ 8 GB：可启用 Meilisearch；需要社交图时再开 NebulaGraph
  • ≥ 16 GB：可考虑完整栈（含 Gorse 推荐集群）
可选基础设施 →
登录密钥 必填JWT 签名，点「生成登录密钥」随机即可
登录有效期 推荐 168 小时（7 天）
数据加密密钥 留空自动生成；生产留空后勿丢 config.yaml
管理员兼容旧版权限 新站关闭，开启会导致权限过宽

安装完成后备份 config.yaml（含所有密钥）。丢失后登录态、加密数据可能无法恢复。

  • 点击测试连接 — 验证 MySQL、Redis、已启用的 Meilisearch/NebulaGraph/Gorse
  • 全部通过后点确认安装，等待建表进度条完成
  • 记录管理员账号密码（默认可能 admin / admin123）
  • 按提示重启 Go 服务
  • 安装成功后 /setup 不可再访问

常见问题

向导打不开服务未启动或防火墙未放行；setup_completed 已为 true（已安装过）
测试连接失败MySQL：库不存在、密码错、远程未授权；Redis：密码错、bind 导致容器不通
想重新安装生产不建议。须备份数据库 → 改 setup_completed: false → 清库或新库 → 再走向导
