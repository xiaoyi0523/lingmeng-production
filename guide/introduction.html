手册说明 ​

面向 站点管理员、运营与部署人员

  • 完成灵萌的首次部署与初始化
  • 在管理后台找到各项配置入口，并按步骤配好
  • 按需开启微信登录、支付、圈子、通知、AI、外卖、跑腿等功能

管理后台入口

https://你的域名/pages_admin/index/index

默认超级管理员：admin / admin123 — 登录后立刻改密码

配置怎么生效（两层逻辑）

全站所有区域共用系统配置、网站信息
区域某校区单独规则区域管理 → 各「××配置」

区域编号 0 = 平台默认；未单独配置的区域继承它。

功能未显示怎么办

  1. 系统设置 → 我的模块 — 是否已开通
  2. 系统设置 → 账号权限 — 当前账号是否有菜单权限
  3. 对应区域配置是否启用
  4. 微信/支付类是否先完成系统配置
  5. 仍不行 → 常见问题
