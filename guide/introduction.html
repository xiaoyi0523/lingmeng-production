本页目录

本文档面向站点管理员、运营与部署人员，帮助您：

  • 完成灵萌的首次部署与初始化
  • 在管理后台找到各项配置入口，并按步骤配好
  • 按需开启微信登录、支付、圈子、通知、AI、外卖、跑腿等功能

您需要准备 ​

项目说明
服务器Linux 云服务器，已安装 宝塔面板
安装包从开发者获取的 lingmeng-x.x.x.zip
Go宝塔软件商店安装最新稳定版
MySQL 8.0+宝塔软件商店安装
Redis 6.0+宝塔软件商店安装
域名（生产）需备案，用于 HTTPS、微信回调
H5 浏览器管理后台仅支持网页（推荐电脑 Chrome）

管理后台入口 ​

text
https://你的域名/pages_admin/index/index

默认超级管理员（首次种子）：admin / admin123。登录后立刻改密码。

配置怎么生效（两层逻辑） ​

层级说明典型入口
全站所有区域共用系统配置、网站信息
区域某校区单独规则区域管理 → 各「××配置」

区域编号 0 = 平台默认；未单独配置的区域继承它。

功能未显示怎么办 ​

  1. 系统设置 → 我的模块 — 是否已开通（说明）
  2. 系统设置 → 账号权限 — 当前账号是否有菜单权限
  3. 对应 区域配置 是否启用
  4. 微信/支付类是否先完成 系统配置
  5. 仍不行 → 常见问题
