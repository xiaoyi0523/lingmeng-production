本页目录

本文档面向站点管理员、运营与部署人员，帮助您：

  • 完成灵萌的首次部署与初始化
  • 在管理后台找到各项配置入口
  • 按步骤开启微信登录、支付、通知、AI、外卖等功能

本文档不是开发手册

不涉及代码结构、API 实现、数据库迁移等开发内容。若您需要二次开发，请参考项目仓库内 docs/ 与 DEVELOPMENT_GUIDELINES.md。

您需要准备 ​

项目说明
服务器Linux 云服务器，已安装 宝塔面板
安装包从开发者获取的 lingmeng-x.x.x.zip
MySQL 8.0+在宝塔软件商店安装
Redis 6.0+在宝塔软件商店安装
域名（生产）需备案，用于 HTTPS、微信回调
H5 浏览器管理后台仅支持 H5 网页 访问

管理后台入口 ​

部署完成后，在浏览器打开：

text
https://你的域名/pages_admin/index/index

默认超级管理员（首次种子数据）：用户名 admin，密码 admin123。登录后请立即修改密码。

配置的两层逻辑 ​

灵萌大部分功能按 「全站默认 → 区域覆盖」 生效：

层级说明典型入口
全站对所有区域生效的默认值系统配置、网站信息
区域某个校区/社区单独规则区域管理 → 各「××配置」页

区域 ID 0 表示平台默认；未单独配置的区域会继承平台默认。

功能未显示怎么办 ​

  1. 打开管理后台 → 系统设置 → 我的模块，查看该功能是否已开通
  2. 到对应 区域配置 页，确认 启用（enabled） 开关已打开
  3. 若为微信/支付类，先完成 系统配置 中相关 Tab
  4. 仍不可用 → 查看 常见问题
