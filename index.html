灵萌适合什么场景？ +

面向校园、区域社区、同城圈子等需要「内容 + 社交 + 自定义服务 + 交易」一体化的场景。一套系统覆盖从发笔记互动到服务表单收单、会员支付的完整链路。

支持哪些客户端？ +

基于 uni-app X 一套代码发布 Android、iOS、微信小程序与 H5 四端。管理后台为 H5 网页，可在电脑浏览器完成全部配置与 UI 搭建。

多区域是如何运作的？ +

平台设置全站默认值，各校区/社区可单独覆盖 UI、用户规则与功能开关。用户进入不同区域看到各自的内容与配置，总部仍可统一管控。

UI 编辑器能定制什么？ +

首页、发现页、个人中心、消息中心、TabBar 等均可拖拽搭建。39 种组件覆盖轮播、笔记列表、金刚区、表单等，按区域保存、即时生效。

为什么选择单体多模块，而不是微服务？ +

简单说：灵萌这类产品，发笔记、聊天、下单、支付、发通知经常绑在一起——用户发一条笔记可能要推消息、写搜索、记积分。单体多模块把这些放在同一个进程里调，数据一致、响应快，部署也只要一套。代码里照样按模块拆分，该独立跑的 worker 也能单独拉出来。微服务要把这些拆成十几个服务，改一个功能可能跨五六个接口，分布式事务、链路追踪、多套部署运维，团队和资源跟不上的话，项目反而跑不动。对校园/区域社区这种体量，单体多模块更稳、更省、更好改。

自定义服务表单能做什么？ +

在 UI 编辑器中拖拽 16 种表单组件，配置字段、计价方式与履约模式，按区域发布不同服务场景——如帮取帮送、预约登记、代办申请、信息收集等，无需为每种业务单独开发页面。
